## 一、普通冷幽默事件首批内容

普通事件以低频插入日常经营，可提供无成本提示或明示选择。文案为项目原创；封闭避难所另按其隐藏随机结果规则结算。

| 标识／事件 | 正文／选择方向 | 实际效果方案 |
| --- | --- | --- |
| EV01 预算终于批准 | “前任政府已批准修复这座建筑。批准日期早于建筑竣工。” | 一次固定少量建设优惠，限定本地，同源效果的叠加上限待核 |
| EV02 盖章的人不在 | “请在工作时间前来。办公室已经连续关闭两百年。” | 纯风味消息，无惩罚，不为笑话强加治理损失 |
| EV03 商人找零 | “对方认真数出两枚瓶盖，并感谢你的长期投资。” | 两瓶盖固定奖励，任何阶段都允许 |
| EV04 机器人欢迎辞 | “欢迎来到本市。你已被登记为第零号合法居民。” | 短期地方秩序／守备效果中的适用一项 |
| EV05 荣誉维修 | 维修人员递交了一张写着“已经尽力”的完工单 | 一次小额维修／补员增益，文案反差但规则提示准确 |
| EV06 炮兵天气报告 | “今日晴，局部地区有我方炮弹。” | 短期指定炮兵招募／训练效果，不随机杀城内平民或军队 |
| EV07 伟大演讲 | 演讲稿遗失，广播员把注意事项连续读了三遍 | 轻微短期秩序变化或纯风味，按当地原型选择 |
| EV08 地图更新 | 新地图终于删除了一座两百年前就倒塌的桥 | 提供一片实际合法视野；不凭事件动态修改桥梁 |
| EV09 可乐促销 | 买两百年前的促销券，送已经没有意义的抽奖资格 | 固定小额收益或主题物品 |
| EV10 员工评选 | 过去一年唯一正常运行的终端当选年度员工 | 小额短期研究效果，不凭空给一整项高级科技 |
| EV11 规范之争 | 两名军需官终于统一了螺丝的分类，螺丝仍然找不到 | 玩家可选小额付费整备或无事结束，效果明示，不套用避难所隐藏结果 |
| EV12 成功的警报 | 警报系统成功通知所有人：警报系统工作正常 | 一次守备提示或短期防御效果 |

事件只对实际有资格的对象结算：EV06只影响有合法炮兵招募权限的对象，不让C11普通无野战军聚落凭事件生成机动军；外交借调炮兵权限仍见地图与种族正文。辐射风暴按[地图6.8节](../地图/战役地图设计.md#68-省级辐射异常风暴与混合控制)处理，与本组风味事件及封闭避难所随机池分开。

效果对象、幅度和可用引用待原型定位，纯风味文本可先落稿。提示正文可以冷幽默，规则栏须明确实际收益与损失；封闭避难所只有开启后才展示实际结果。

## 二、马德雷：财富与全息玫瑰

### 地区、守军与战斗条件

以利亚控制P23A马德雷赌场，单省唯一城，红雾造成区域损耗；控制方无野战军，强驻军包含以利亚、克里斯汀、迪恩、狗／神及幽灵人、全息守卫。具体驻军编制、人物战斗宿主与红雾数值由种族／战斗维护。指定城内发射设施存续时全息守卫不可受伤，摧毁对应设施后才能伤害守卫；设施标识、目标绑定与AI攻守待技术核对。

维罗妮卡为传奇事务官。她以敌于守城方的身份实际参加本次战斗（包括实际入场援军）时，克里斯汀自行引爆项圈自杀，从本次守军移除。附近军队、援军候选名单或其他地区出现不算实际参战。助手初设按战斗实例记录一次触发；读取战斗存档、援军多次刷新不重复移除或生成替代人物。她未参战或克里斯汀已不在守军时按当前实际守军继续结算。

### 首次占领与永久废墟

首次占领赌场的胜方先取得一次巨额财富（金额待定），保存战利品与占领军，然后执行爆炸结局。城镇改名为**马德雷赌场废墟**，永久仅一个建筑格，唯一不可升级建筑为**全息玫瑰碎片**，城市每回合总收入仅**1瓶盖**。主聚落、资源、其他槽位及继承建筑不得额外产生城市收益；地面与任何外来槽位的建设权限需满足这一永久结局。带走的财富和占领军均保留，爆炸不执行占领军毁灭。

助手初设顺序：首次占领锁定胜方与地点→发放财富并记账→爆炸、改名和建筑状态转换→核对总收入与存续军队→显示最终弹窗。易主、重占、合邦及读档保留首次结算标记，财富不重复领取；中断时从已完成步骤续办，不重发奖励。永久废墟不得借毁城重建恢复赌场。强制单槽、主链停收及跨文化继承是否可表达待技术验证。

### 固定结尾文本

无论克里斯汀分支是否触发，最终爆炸弹窗固定附以下原文。该段仅为叙事，无物品奖励：

一个带着兜帽和动力拳套的女子前来，穿过赌场废墟，停在破碎的全息玫瑰投影下，沉默良久，留下一个指环离开了，指环的形状是两朵触碰的玫瑰，其中一个光滑明亮，另一个已经生锈了。

## 三、维加斯：赌场与自由城

### 互斥开局与首回合选择

豪斯／好好先生互斥选择P05A幸运38的同城开局，共享额外贸易与外交派系加成，领袖与初军不同。好好先生初始拥有唯一邮差而初军较少，邮差初始化沿唯一实例规则，六位同伴独立招募见第七节；自治赠军独立结算一次并正常维护。金钱外交及智能升级按所选领袖绑定专属成长承载，权限由维加斯机制维护。P05为单省四城：幸运38、三大家族赌场区、猫王帮自由城、恶魔帮第三避难所／南部废墟；地理分组为战略抽象初设。

所选维加斯统治派系在第一回合进行一次选择：玩家显示两难，AI按策略自动选择，并调用同一结果结算。AI策略助手初设为自治优先，以顺畅接管赌场和推进统一；AI选择与同回合事件队列尚未验证。

| 路线 | 领土及赌场 | 军队与代价 |
| --- | --- | --- |
| 自治 | P05B城镇及顶尖、蛾摩拉、超豪华三个赌场原样交统治派系，以收入修正体现40%分成 | 额外获得一支部队；助手初设为普通领主率小规模联合安保，承担正常维护与额外军队经济负担 |
| 武力 | 与三个家族明确敌对，击败后取得P05B并重建赌场，经营收入高于自治路线 | 按实际战斗与修复投入推进，无自治赠军 |

三地标各一个，集中在P05B，独立建筑记录与槽位容量待技术核对。40%分成的计算口径统一引用[维加斯机制](../种族/维加斯/种族机制.md)，具体作用对象、税基与结算顺序仍待核。武力路线以赌场建筑重建后的实际取得为后续条件；自治路线以保留建筑转入统治派系为取得条件。

### 猫王谈判与恶魔帮

统治派系取得任一有效赌场建筑的**同回合**，在赌场取得结算完成后触发一次猫王帮谈判：

| 选择 | 结果 |
| --- | --- |
| 加入 | 整合P05C自由城，获得猫王传奇事务官，秩序与经济作用由种族人物正文维护 |
| 敌对 | 与猫王帮交战；击败后获得NCR好感及“银色冲击的馈赠”20回合 |

馈赠初设为派系效果：弹药容量、武器威力及招募费用减免，幅度、单位筛选及叠加由战斗／种族核对。敌对分支的“击败”助手初设为该猫王地方派系失去最后据点、完成本次征服；不以任意一场路过野战重复领奖。加入后猫王只创建一个实例，敌对后不得再走加入奖励。

恶魔帮P05D只能通过击败取得；它不进入自治移交、猫王谈判或友好整合选项。第三避难所的完整／遗址类型须与避难所专项单独核对，地名本身不创建封闭型随机发现。

猫王谈判由玩家选择，AI策略助手初设为优先加入；双方走同一整合或敌对结果，实际可用性待核。

同回合处理顺序：首回合选择→领土／建筑移交或战后重建→赌场取得事件→猫王谈判→所选结果。多个赌场同回合取得只排一个谈判，事件队列在当前弹窗结算后继续，不推迟成下一回合。读档保存选择、建筑取得、谈判排队和奖励步骤；自治赠军、事务官、好感及20回合效果各只发一次。城镇／家族转交与多地标同城组合未验证。

## 四、大分水岭：导弹中枢

### 线性推进与终点资格

尤利西斯为不可玩特殊势力，无野战军，依靠四城强驻军防守。曲折峡谷内唯一相邻链为P15B霍普维尔入口→P15C高架公路军事区→P15D阿什顿废墟→P15A尤利西斯神殿／导弹中枢（省会）。这是战略地理抽象，地图源需确保两侧阻隔及特殊移动权限维持该通路。

首次在末城取得胜利的派系获得特性／专属装备，并进入四选一终点事件；具体特性、装备及数量由战斗／种族维护。助手初设在正常占领操作前锁定实际胜方领主、胜军与终点区域，暂挂普通战后操作，先确定分支后执行对应占领／废墟结果，防止先结普通占城再重复终点奖励。

| 选择 | 目标与结算 |
| --- | --- |
| 荒漠核爆 | 合法荒漠目标地区转为辐射，提升所有其他派系好感；范围、目标列表与数值待定 |
| 敌对首都核爆 | 选择实际敌对派系首都，城镇成为废墟；所有其他派系好感降低，含目标方。外交关系与目标城有效性在确认时再核对 |
| 原地爆破 | 末城成为废墟，执行军部队覆灭；执行领主按传奇负伤恢复方式存续，取得“核爆幸存者”：辐射损耗免疫、高额特殊保护、近身敌军烧血光环；同时取得高质量全局增益及大量全派系好感。具体效果由战斗维护 |
| 和平 | 仅邮差属于胜方、随胜军且位于终点区域时可选。尤利西斯加入传奇领主，授予全派系跨战斗共享三次战术核弹总额度，参考伊克特末日火箭；扣除事件触发当回合正收入的一半 |

和平费用以事件触发时保存的当回合正收入为基数，收入为零或负数时费用为零，取整规则待定；选择显示时明确实际费用，扣款失败的处理待技术核对。核弹额度按派系共享保存，其他军队使用同一剩余次数，额度的战斗消耗与存读档交技术验证。

普通领主执行原地爆破的传奇负伤恢复宿主未核实，必须保留执行领主存续目标；能否临时持久化身份或采用其他原生恢复对象待技术比较，不能按普通死亡结算假定完成。首都易主、敌对关系变化、目标不合法及邮差不再满足条件时，应重新核对可选项，不能自动改成另一分支。

### 和平事件原文

尤利西斯奄奄一息，拿着核弹控制器和你的军队对峙，逼你做出选择，这时候邮差走了过去，和尤利西斯叽叽咕咕说了半天话，然后吭吭哧哧把核弹拆了，然后你就多了个强悍的首领和三颗战术核弹，感谢邮差，给他些瓶盖吧

终点首次胜利、基础奖励与分支选择分别记账；四分支互斥，只执行一次。和平仅创建一个尤利西斯领主；原地爆破先保存执行领主身份和恢复目标，再清除部队；其他核爆先锁定合法目标再改变地区。若结算中断保留已选分支与未完成步骤，恢复时不重发装备、核弹或外交效果。

## 五、大山脉：统一与开放

### 和平开局与首次进入

F21智脑与F42莫比乌斯共享基础兵表及经营，关系差但开局不交战。两派AI倾向维持现状，同时正常建设、防御和应对入侵；这是AI倾向，玩家及实际外交仍可改变关系。本族玩家可先经营自己的两城、清理失控实验体据点，再选择是否宣战统一。失控据点与两派占有者、环路和探索通道唯一见[地图6.3节](../地图/战役地图设计.md#63-跨省通行骨架)。

统一前当地两派均不能外出，外部军队可入可退，外部AI不主动传送进入。外来玩家派系首次进入时，在安全落点触发一次四选一；进入本身不自动宣战。具体条约组合为助手初设，选项规则栏在确认前显示合作对象、战争对象、通行及联防结果：

| 选择 | 初设外交结果与可行动范围 |
| --- | --- |
| 帮助智脑 | 与F21和平合作，候选双向军事通行＋防御同盟；与F42显式交战。可协助F21清理失控据点或进攻F42；双方领土与兵源依各自权限 |
| 帮助莫比乌斯 | 与F42和平合作，候选双向军事通行＋防御同盟；与F21显式交战。可协助F42清理失控据点或进攻F21 |
| 同时对两方开战 | 外来玩家与F21、F42分别交战；两派建立针对该玩家的共同防御关系，候选双向通行＋防御同盟，并共同对该玩家作战。条约、共同敌人与实际增援资格分别核对 |
| 与两方和平探索 | 与F21、F42均保持和平；探索双方未占的区域，可清理失控实验体荒废城市。正常领土与通行权限仍有效，此选项不自动授予两派城镇驻扎、招募或占领权 |

帮助分支建立的是外来玩家与所帮一方的合作及对另一方的战争，是否同时要求当地援助方加入该战争须按显示的实际条约和开局状态核对；初设不以暗中替当地AI强制宣战作为前提。双战分支明确建立两方共同对抗同一外来玩家的关系；对其他世界势力的外交仍各自处理。

助手初设顺序：登记首次进入与安全落点→暂停后续可导致强制开战的动作并排出选择→读取实时外交、显示四项结果→确认分支→逐对结算外交及必要条约→恢复正常行动。玩家在选择前可和平抵达安全空间，选择结果完成后才允许对应攻击操作。外来独立事务官能否触发、与军队共用首次进入记录的方法待技术核对。

四选一按外来玩家派系保存一次，所有军队及重复进出共用结果；读档保存待选择、已选择及各条约结算进度，完成后不重新给选项或重复缔约。实际战争变化、首次进入前已有战争、目标派系被消灭或处理途中发生盟约参战时，必须重新核实可执行选项。和平分支若需结束现有战争，其可用性及结束战争的关系链须明确显示并交技术核对；未确认前保持安全结算停点，不擅自选边或覆盖已有战事。低好感本身不作为战争判定。

和平探索与帮助关系在首次选择后仍受正常外交变化影响；选择不是永久免战。AI禁止自行统一开放、两派AI维持现状及共同防御可用性、外部AI传送策略及事件先于攻击的拦截均未验证。

### 统一门槛与开放

本地玩家统一条件为消灭另一方，核对两派实际存续与玩家胜方身份。AI控制的大山脉不得自行完成统一开放：即使外来玩家帮助本地AI消灭其对手，本地AI也不触发这两条统一剧情及向外解锁。第三方占有、双方同时覆灭及无有效本地玩家胜方时保留当前出区限制；杰森玩家坠落的剧情破障由第十一节独立记录。

| 胜方 | 统一事件叙事与解锁 |
| --- | --- |
| 智脑联合体 | 恢复记忆，关闭雷达围栏，携带技术走向外界重建文明；解锁本派系向外使用入口，扩张倾向恢复 |
| 莫比乌斯 | 博士们最后反扑摧毁围栏并逃亡；莫比乌斯为阻止危险技术危害外界决定追击，解锁本派系向外使用入口及危险技术追踪任务 |

统一标记按胜方派系保存，触发时先保存事件结果和外出资格，再显示叙事；读档、重复占城和反复刷新入口不重复解锁或发奖。外部远征军既有进退权限保持；外部AI仍按不主动传送进入处理。权限检查同时读取控制者类型与剧情破障标记；合邦、势力重生及控制者改变后的继承待核，AI不能借普通统一条件自行开放。

### 智脑实验提案

下述科研与人物获取仅在对应人物仍存活、未被杰森坠落永久死亡状态禁用时执行。克莱因为智脑联合体唯一传奇领主，同一实体兼任科研职责；博罗斯、达拉、0号、8号为四名传奇事务官。专业分配为助手初设：克莱因脑机／指挥、博罗斯生物、达拉人体／感知、0号机械、8号声学。恢复对应设施后解锁项目，定期通过原生两难入口提出资助方向；玩家选择方向并支付瓶盖及统一研究资源，随后随机结算成果、异常成果或事故。成果类别为装备、单位强化、有限招募或能力，项目内容、间隔、权重与费用待种族设计。

优先比较斯洛特实验强化／不稳定与原生两难事件的组合。方向可选择、结果不可控；同一提案只付一次费用、只结一次结果，读档保存已抽结果。科研项目使用种族统一资源和权限，不由世界事件另设第二份资源。科学家加入、设施受损中断及实验事故对象待核。

### 莫比乌斯追踪

机器蝎防御体系沿种族正文，少量装甲／维修／能量改良、巨型单位受容量约束。统一后危险技术追踪参考欧西约坦的威胁目标选择与任务奖励；按现有陆路和入口前往目标，奖励机械部件、专属装备或机器蝎升级。目标资格、路径可达性、任务数量与重复奖励由种族／技术核对；任务发布须满足统一后的实际出区权限。

### 安全退场、存档与去重

永久离队按“玩家派系＋人物身份”记录，随当前战役存档保存，与死亡、负伤及普通解散区分。在该存档已记录离队的状态下，恢复和平、解散／重招或重新载入均不得重复领取该伙伴；获取任务、人物池及其他奖励入口共同检查同一离队标记。离队状态的存读档与领取入口去重待技术核对。

维罗妮卡的马德雷事件只看她在该战斗敌对侧实际参战。助手初设以战斗开始／援军实际入场状态记录资格；离队排队后如何排除后续战斗参与、同一结算链中人物失去归属如何处理，需与马德雷战斗触发统一验证。固定玫瑰结尾不受队友获取、永久离队或克里斯汀分支影响。

六位同伴任务和人物状态独立于邮差负伤、离队与军队位置；各自保存唯一实例、领取和离队状态。所有新增任务、战争筛选、英雄唯一性、装备和存档生命周期均未验证，集中技术记录归[验证方案第十节](../../可行性验证/首批可行性验证方案.md#十当前设计组合待验证清单)。

## 十一、杰森伟大旅程：坠入大山脉

### 玩家资格与远航准备

仅玩家控制F27可完成伟大旅程；AI杰森必不完成。天启通信实际来自莫比乌斯，附带大山脉坐标；请求耐辐射志愿者、杰森误读信号为天启是助手叙事初设。远航准备采用现有研究／修复任务、设施及物资费用，具体数量待种族确定。完成准备后选择一支实际军队及其中实际随行人物发射，显示军队、人物、代价和原领土保留情况；杰森须作为同行人物存续。原研究院P12B可保留，不因发射自动放弃全部原领土。

助手初设发射在军队脱离战斗及其他结算时进行：保存原军及人物、兵种、经验、装备和当前生命→锁定发射资格与费用→原军进入转移状态→结算坠落。火箭撞毁屏障后坠入大山脉，军队和杰森受损但存续，损耗幅度、人数及最低存续处理由战斗／技术核对；以原军转移实现，不重复生成完整新军。

## 十二、铁路、英克雷与学院的地方行动

### 铁路安全屋与救援

铁路F36开局为小行动队加他方城镇安全屋，黛瑟蒙娜等原作人物承担行动。安全屋设施分观察线索、接应／救援、长期支持收入／志愿者、隐蔽整备四类用途，具体建筑与数值由种族维护。救援或护送成功可扩展隐藏网络；每次解救后选择安置幸存者以取得当地长期支持，或接纳自愿参战者／特殊人物，人物唯一性与有限兵源按实际身份检查。

转型前普通攻城按任务释放或交合作方后保留安全屋为初设；学院固定原首都的任务接管按下述例外执行。搜捕、宿主失守及安全屋暴露可触发撤离／救援，保存实际人员、待救对象及任务进度，按合法节点撤离或投入有限行动队，重复回调不重发志愿者。无城阶段存续、隐藏槽位及搜捕组合待验证。

#### 学院成果与公开转型

固定学院原首都为地图P20A，按原始城镇ID保存。学院独立且仍存续时，铁路实际攻破并接管学院中枢后取得完整资料／设施。若学院已被其他AI灭亡，铁路攻占被占的P20A或殖民其废墟后，必须触发地下学院残余任务战；胜利取得同等完整成果。临时迁都、原址再次毁城或殖民不抹除任务资格；学院仍有其他据点存续时按现实战争／接管路线判断。

原址先接管是无城阶段的任务性例外。任务胜前仅保存接管与任务入口，不开放普通地表经营、制造奖励或强制合邦。地下敌军用预设学院守军，任务失败保留重试，实际损失正常承担；胜利记录一次。任务中原址再次失去时暂停并待合法重获后续办，不重复发资料。

胜利取得学院成果后自动强制整合阿卡迪亚，按固定P20C原址记录执行：仍存续则接收其实际城市、军队和唯一迪玛；已灭且原址被第三方占据则直接转城，已成废墟则事件恢复为铁路可经营起点。两种已灭结果均接收／恢复唯一迪玛，检查负伤、被俘、他方归属及死亡状态，不能同时存在第二实体。阿卡迪亚灭亡时不重建历史全部军队；第三方驻军、野战军的安全移出／合法落点与外交响应待核，强制交付不追加谈判或再次攻城前置。

事务顺序为锁定学院成果→保存转型待完成→交付阿卡迪亚实际领土／原址及迪玛→接入完整学院建筑序列、适用科技和制造权限→开放普通占城经营→显示完成。已灭学院地表破坏不削减地下资料设施成果，具体科技完成进度为助手配置初设。保留F36、黛瑟蒙娜、安全屋、救援、安置与情报机制，继承阿卡迪亚合法既有内容和任务状态；“合成人自由邦”为公开名称候选，不新增开局。学院高级监狱若继承仍须满足相同升级、长冷却及全领主条件。

每步保存实际对象、完成状态及待交付记录；失败或载入从未完成步骤续办，不重新创建迪玛、重发资料或反复强制交城。任务接管、地表开放和强制整合必须按同一事务验证。

### 福音降临：一次性城镇行动

“福音降临”为行动候选名。狂信徒寄生者在指定城镇执行一次性行动并被消耗，造成辐射爆炸，产生较弱辐射生物军队。以下空间与结算流程为助手初设，组合未验证。

目标为实际存在、事务官可合法接近的城镇，范围初设限其所属地区；特殊入口及独立事务官通行遵守地图现有权限。爆炸按同等辐射风暴结算地区建筑损坏和区域军队损耗，继承[地图6.8节](../地图/战役地图设计.md#68-省级辐射异常风暴与混合控制)的地区防护、异形单位损耗免疫与异形建筑损坏免疫。驻军、围城军与混编单位筛选仍待核。

弱生物军初设归女王控制，使用既有合法生物条目并承担种族规定的维持，生成于目标地区合法陆地，避开城镇中心、军队占位、不可通行地形、特殊入口安全落点及封闭边界外侧。无合法落点时行动暂不可用且不消耗事务官；敌城附近的接敌空间待核。

一次行动只消耗一个执行者、产生一支实际军队，不额外结算俘虏、肉食或自然孵化库存。初设不重置整省周期；若与自然风暴同窗覆盖该地区，合并一次暴露并保留来源，周期仅由合法终点重置。中断或载入保留已经发生的消耗、损伤和军队，继续未完成结果；技术记录与执行方案统一见[DV-052](../../可行性验证/首批可行性验证方案.md#十当前设计组合待验证清单)。
