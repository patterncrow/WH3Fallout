# 合成人：学院制造、铁路隐网与阿卡迪亚

更新日期：2026-11-10。状态：三派身份与方向已定；费用、目标、生产及网络组合初设，未验证。依据：[总纲](../../设计总纲.md)，技术依赖见[集中待验](../../../可行性验证/首批可行性验证方案.md#十当前设计组合待验证清单)。

## 三派权限

学院与铁路可玩，阿卡迪亚为小型避难共同体传奇AI。学院自营生产／科研／能源原料据点；铁路转型前以无地表城的安全屋网络运作，取得学院成果并强制整合阿卡迪亚后开放正常占城建设；阿卡迪亚居民定居与有限合作，分别配置来源与身份。

## 学院：生产与研发

自营城镇和能源／原料设施支撑持续制造普通一、二代合成人，研发专业型号、有限追猎者，科学主管组织生产研究，追猎者与渗透人员承担专业行动。常规财政与已有知识／渗透用途各自支付，不额外模拟逐枪工业原料；具体资源与负荷沿原型选型。

普通建筑提供Gen1／Gen2持续生产，专业训练提供Gen3渗透小队，专业研发与有限设施提供独立限量U03追猎者，既有单位类别升级参考TW-SKV-04。研发是迭代专业型号，与兄弟会回收资料／修复既有军械恢复兵源容量区分。普通一二代型号表现可复用基础资产，不为代际填满同质兵表。

## 学院：有限渗透与回收

条件行动沿原生付费目标行动结构比较，萨尔式结构仅取目标、费用、前置与冷却，不继承终局或全部干预清单。

| 行动方向 | 结果初设 | 范围 |
| --- | --- | --- |
| 窃取研究 | 取得适用研究收益或线索 | 合法科研目标、费用与冷却；不无条件复制整棵科技 |
| 假情报 | 指定军队侦察／行军／伏击防御有限削弱，择具体效果 | 有限对象与持续，解除条件待核 |
| 破坏军事设施 | 损坏指定合法招募建筑 | 普通建筑损坏与修复结构，不以摧毁整城或抹除整军替代 |

回收逃亡合成人可取得资源或有限兵源，影响铁路／庇护者关系，具体任务资格与结算引用[世界事件](../../事件/普通事件设计.md)。任务人物可对命令产生疑问为初设，人物选择与代价待写具体任务；不自动增加全员忠诚新系统。研究收益、回收及特定高级兵各自去重，不能同一回收反复发兵。

### 首批学院任务（助手初设）

以下借原作秘密人员、地面试验与回收行动的故事，具体目标和结果是Mod组合。行动参考萨尔式付费目标操作及原生任务／两难；相关人物可以出现在任务叙事中，不因一次任务新增可招人物或派系。任务全文与实际目标由世界维护。

| 任务／类别 | 原作题材与玩家行动 | 成果、代价与选择 |
| --- | --- | --- |
| 市长的密报／假情报 | [Political Leanings与麦克多纳的报告](https://fallout.fandom.com/wiki/McDonough)提供秘密行政人员素材；在合法敌对军队周边支付情报行动费 | 指定一支军队短期伏击防御降低，帮助真实小队或普通军作战；次数、费用、冷却受限。被揭露产生目标派系关系损失，不能代替战斗或直接命令该军撤退 |
| 地面试验数据／窃取研究 | [Building a Better Crop](https://fallout.fandom.com/wiki/Building_a_Better_Crop)的秘密田间试验，取得目标科研设施的环境／生产资料；原作试验与Mod窃取用途分开 | 获得一次适用研究进度或一条项目线索，二选一。支付行动费并承担关系代价，目标须有实际适用技术；回收普通农业数据不解锁动力甲或复制整棵科技 |
| 错送的军需单／破坏军事设施 | 取合成人冒名潜伏题材，向一个实际敌对据点的招募设施投送假订单；具体破坏情节为Mod架空 | 支付费用损坏一座已存在的合法普通招募建筑，敌方可正常修复；只延误实际供给。侦察不到目标或没有可破坏设施时不生成该任务，强地标与剧情城镇按各自权限 |
| 逃亡者成了首领／回收 | [Synth Retention](https://fallout.fandom.com/wiki/Synth_Retention)的加布里埃尔题材，追猎队面对已经加入武装集团的逃亡者 | 完成实际任务战斗后，执行回收可选有限研究结算或一笔合法补充资格，影响铁路／庇护方关系；放弃回收则放弃该奖励，保留关系并结束此案。不是无代价同时获取人手与庇护者信任 |

三类干预只取上表的一个具体首版效果，其他同类作用域仍是待选候选；回收单独使用现有任务结构。学院投入有限行动费协助常规战争，制造体系仍负责持续兵源，不能依赖不停生成逃亡者支撑主力。被放弃、安置或回收的同一对象分别持久记录，不循环刷新为任务奖励；对学院与铁路同时涉及的对象由世界同一事件结算。

原型存在不代表匿名行动、暴露判定或建筑损坏组合可用。若没有低成本隐秘结算接口，先用明示目标／外交代价的付费任务；假情报用短期指定效果、研究用一次性进度、破坏用原生损坏与正常修复，三类局部行动本身不结算派系控制；控制沿下述高级监狱与全领主处理条件。

## 学院：监狱升级、全领主替换与受控政权

### 采用方向与原型

采用艾萨里昂监狱的俘获／洗脑结构，逐步升级至一定程度才能洗脑，洗脑有较长冷却；只有某派系所有领主都曾被俘并洗脑，才能触发事件强制附庸。军事击败提供俘获机会，附庸在全领主条件完成后结算。

具体原型为TW-HEF-04艾瑟塔玛哈：俘虏、处理选项、要塞修复与升级。原版监狱存在不等于“全领主洗脑后附庸”已经原生提供；后者是本Mod的条件事件组合。原版洗脑收益不整套继承，先取本方案需要的身份处理与释放记录，不另叠收入抽取。学院已有萨尔式三项干预继续做局部行动，控制政权单独满足监狱条件。

### 首版流程初设

| 阶段 | 玩家主要行动 | 权限与投入 |
| --- | --- | --- |
| 拘押审讯 | 建初级设施，在实际战斗中捕获适用领主，进行普通处理 | 少量牢位，俘获和处理沿原型；此时尚不能洗脑或强制附庸 |
| 行为研究 | 支付瓶盖和已有科研投入，完成实际监狱升级 | 建立中间成长阶段，获得已有拘押／审讯改良；抓到一个弱小领主不能跳过设施投入 |
| 高级替换 | 达到高阶监狱并完成相应升级后解锁“洗脑”，初设与T4科研／监禁条件衔接 | 具体层级、前置与成本由助手沿原型配置，不能只靠基础监狱开局控制小国 |
| 逐个放回 | 处理已俘领主，记录人物及目标派系，再释放回原组织 | 长冷却由学院全派系共享；多牢房能容纳人质，但不并行洗脑绕冷却 |
| 指挥链接管 | 检查目标仍存在且全部有效领主均有处理记录 | 触发一次强制附庸事件，不另叠普通外交好感说服门槛；普通战胜和未完成处理均不触发 |

瓶盖与已有科研资源负责建设和替换，不新增人体样本货币。“洗脑”作为界面工作名，辐射叙事表现审讯取样、制造合成人替身并放回。俘获沿原版指定战场能力与结算考察，不预设战败必定被抓；特殊事件若提供俘虏，也须为同一实际人物，照常经过设施、冷却和处理。

原作秘密人物及[Reformation](https://fallout.fandom.com/wiki/Reformation)中用替身改变组织路线的情节提供题材，把整个派系统治层接管为Mod架空扩展。特殊人物保持已定形态：例如豪斯处理其指挥机体、维护和指令接口，不制造人类豪斯克隆；具体对象能否使用同一监狱流程分别待验。

### “全部领主”的计数与取舍

- 条件针对目标当前已实际招募、仍存续的普通与传奇领主，包括负伤待归者；未生成的随机候选和从未登场的传奇招募池不作穷举。事务官不额外加入本次全领主门槛。
- 条件要求历史上都已被俘并处理，不要求同时关押全部领主。处理后放回，继续追捕下一位；同一人物负伤回归保留记录，重复俘获不增加数量，不发重复永久奖励。
- 触发前目标新招募或合法接收的领主也必须处理。玩家可以打击财政与招募、追击分散军队或承受更长周期；对方扩军与反击形成现实阻力。
- 记录绑定同一人物和实际所属，释放不复制人物、经验或整支军队。转派系、合邦、解散待招及永久死亡的名单更新分别待技术核对；杀死未处理领主不等于洗脑完成，不能把一次领袖被杀误判为全派系接管。暂时零领主不能按空集合直接附庸。
- 高阶解锁与全局长冷却是共同门槛。后期接管一位领主的小势力可以成为前期投入的回报；大型势力需要多轮实际俘获和长期处理。冷却、牢位和现有制造／军费承担投入，不另增一套替换者日常维护账本。

### 接管成果与最终胜利

原生附庸作为战役承载：目标保留旗号、城市、人物与兵种体系，按附庸规则供款、参战和接受战争协调。其AI经营与全部军队不会因此自动转为学院直接操作；借军若采用，仍沿原生权限与代价。人物替换记录本身不再额外抽取一份相同收入。

设计要求已经完成替换的统治层保持受控，不因原有种族外交厌恶立即反叛；宗主灭亡、第三方解放与归属变化需核对。控制前各势力仍正常独立作战。政治上的完全操控，用受控政权与原生外交／战争权限表达，面板可见性和操作范围需如实显示。

最终胜利按检查时地图上当前独立存续的莫哈维主要势力判定：除学院自身外，所有合法主要势力均已受控即完成。世界提供主要势力的政治身份范围，实际实例随当时存续与归属更新；已控制附庸计为满足，代理及附属不另当独立政权重复计数，普通同盟不算受控。

已灭亡势力退出独立目标；被合邦者归入现存承接大势力检查，不要求恢复旧主体或复活旧领主。检查时新出现或恢复独立的合法主要势力加入当前目标。此动态目标规则不改变单个目标的高阶监狱、全局长冷却与全部有效领主处理条件，也不把单次战败算作控制；名单与胜利结算仍待技术核对。

### 技术依赖与可接受备选

需核监狱跨文化、俘获能力、牢位、处理与释放、全局长冷却、实际领主名单、持久标记、特殊领主体适配、强制附庸资格和稳定。原版旧版本曾有[援军领主俘获问题](https://community.creative-assembly.com/total-war/total-war-warhammer/bugs/4444-eltharion-s-warden-s-cage-ability-bug)，这里只作为当前待核点，不据旧报告判断本机版本成败。

专属面板若成本过高，可先用原生任务／两难承载拘押、升级和处理，保留实际俘获、高阶解锁、全局长冷却、全领主处理的完整条件。不能把实现备选简化为“打赢就附庸”或“洗脑一名领袖就控制”。所有接口均未验证，测试继续暂停。

## 铁路：无地表城镇的安全屋网络

整体参考变化灵式隐藏设施／地区任务（TW-TZE-02）。转型前以小行动队及安全屋开局，地表由其他势力持有，无地表主链、城镇税收和学院工厂。

| 安全屋用途 | 产出初设 | 限制 |
| --- | --- | --- |
| 观察联络 | 地区观察与任务线索 | 合法范围、发现风险 |
| 接应救援 | 救援／护送行动及有限人员 | 费用、任务条件与周期 |
| 社区支援 | 当地支持、有限收入／志愿者 | 非地表税收，来源只结一次 |
| 隐蔽整备 | 低成本行动队补充与有限恢复 | 撤离风险、兵源及装备有限 |

救援和护送推动网络扩张。解救后可安置，为当地形成长期支持／收益，或接纳自愿参战者／特殊人物；同一批人员不能同时按安置和加入重复领取。弱基础主力配少量专业行动队，不以一次救援开放全部追猎者或生产资格。

地下阶段攻下普通城镇后的初设处理为任务释放／交合作方，并保留合法安全屋；此阶段普通城镇交出；学院原首都任务性接管为例外，具体沿下述转型。合作方、战后选项和网络继承交世界／技术核对，不以普通占城临时长期保留作为完成。失守或搜捕触发安全屋撤离／救援，人员去向、损失和隐藏设施结算待核，仍维持实际小队与可恢复网络。

## 铁路：夺取地下学院、强制整合与公开建国

学院隐藏位置与强首都守军使其难被AI攻陷，但不设置AI不可攻击或必不灭亡规则；空间、入口与城防配置由世界／种族正文落实，AI能否发现、接近及进攻仍需验证。铁路的接管链无论学院是否先被第三方消灭，均有明确可完成路径。

### 两种取得学院的路线

| 学院状态 | 铁路行动 | 战斗与结算 |
| --- | --- | --- |
| 学院仍为独立派系，铁路亲自推翻 | 按原路线攻破学院中枢，完成实际接管战斗 | 胜利取得完整技术资料与建筑设施，接入下述强制整合事件 |
| 其他AI已消灭学院，首都被占领 | 铁路重新攻占学院原首都 | 地表攻城后触发独立任务战斗：发现藏于废墟底层的学院残余，战胜后取得完整技术资料与建筑设施 |
| 其他AI已消灭学院，首都已为废墟 | 铁路殖民学院原首都废墟 | 殖民仍触发同一任务战斗，不能用无战斗殖民直接领取接管奖励；获胜后取得同等资料与设施 |

学院原首都按世界初设P20A的固定城镇身份记录，阿卡迪亚原址为P20C；归属沿世界6.11，临时迁都不改变标记。学院若还有其他据点且尚未灭亡，不按“第三方已经消灭学院”处理；沿现实学院战争／接管条件判断。战役中第三方继续毁城或重新殖民，也不能抹除该原址的地下残余任务资格。

地下残余提示与任务全文见[世界事件](../../事件/普通事件设计.md)，本页维护种族权限。

任务战斗采用普通任务战斗、预设敌军和一次性奖励结构；地下残余是任务敌军，不另建可扩张派系或正常战役野战军。敌军以学院既有合成人和有限防卫人员组成，配置由助手沿原兵表收敛。尚未赢得任务战斗时，接管处于待完成状态，不授资料、制造权限或强制合邦奖励。失败保留重试路径，实际部队损失正常承担，不赠送免费替代军队；完成标记唯一，不因重占、殖民或重打而重复领取。

夺回／殖民原址是地下阶段的任务性接管例外，任务完成前只承载接管与战斗入口，不开放普通地表经营；胜利后统一解除地表限制。占城结算与任务失败后的合法归属需技术衔接，接管与战斗按此顺序结算。

### 胜利后强制整合阿卡迪亚

取得学院成果后，由同一事件链自动进行，不以好感、谈判或阿卡迪亚存续为前置：

| 阿卡迪亚状态 | 必然结果 |
| --- | --- |
| 派系仍存在 | 强制事件合邦，接收其实际城镇、军队与领主 |
| 派系已灭亡，原址由第三方占据 | 强制将阿卡迪亚原址城镇转给铁路，接收／恢复其唯一领主，不要求铁路再次攻城或外交购买 |
| 派系已灭亡，原址为废墟 | 事件使铁路取得原址，恢复为可正常经营的合法城镇，并接收／恢复其唯一领主 |
| 原址已经属于铁路 | 确认现有所有权并完成领主继承，不重复发城、军队或同名人物 |

阿卡迪亚领主沿既有迪玛唯一实例转归／恢复，派系覆灭不阻止其继承；负伤、被俘或已归其他势力的异常状态按唯一人物统一结算，不创建同时在场的第二个迪玛。派系仍在时接收实际部队；派系灭亡时不凭空恢复其历史全部军队。原址交付为强制结果，第三方的实际军队、驻军与外交响应由世界／技术处理，不额外添加关系或同意前置。

### 合成统一政权的能力

铁路保留F36、黛瑟蒙娜与原有安全屋、救援、安置、情报和行动队机制，同时接入阿卡迪亚既有领主及适用地方经营／修复／任务内容，成为学院灭亡、阿卡迪亚并入后的统一合成人政权；公开名“合成人自由邦”仍为助手候选，不新增第四个可玩开局。

战斗缴获的是完整学院技术资料与地下保存的建筑设施，原首都的地表毁灭不削减这笔剧情成果，也不要求寻找额外幸存科研人员才成立。取得完整学院建筑序列、适用科技和制造权限，自此可正常占领城市并建设。仅继承生产、经营与装备研究的适用科技；专属阴谋行动分支保持学院权限，具体科技完成进度与资料对应由助手统一配置，不受已灭亡AI记录丢失影响，也不新增一条资料找回门槛。

| 内容 | 转型后的结果 |
| --- | --- |
| 地表经营 | 解除地下阶段限制，可以正常占领、建设和发展城市 |

| 原铁路网络 | 安全屋、救援、安置与情报继续有效；同城安全屋与地表税收不重复结算同一收入 |

### 胜利阶段与原型依赖

短期以地下组织和首条救援线站稳脚跟；推翻学院或击败其地下残余、强制整合阿卡迪亚为中段组织转型；最终在莫哈维公开扩张，掌握重要领土、能源和交通，击败军团、英克雷等现实主要敌手，形成统一合成人政权。

原型组合：变化灵式地下开局、原生任务战斗、条件事件合邦、指定城镇转交与废墟恢复、原有建筑科技分支解锁。学院原址的额外战斗与奖励是明确设计，不据原版任务存在宣称组合已通过。

需核固定原址标记、AI灭亡判断、攻占／殖民后触发、任务失败重试、接管阶段城镇权限、建筑恢复、资料与研究继承、无条件合邦、第三方原址强制转交、唯一领主恢复及同事件去重。低成本使用预设任务敌军与一次性奖励、预设共享建筑科技权限，不运行时创建新种族或新国家框架。技术测试继续暂停。

## 阿卡迪亚：避难共同体

迪玛领导普通居民守备，以有限修复、生存与地方外交维持，不拥有学院制造或铁路完整网络。任务沿FO4远港内容：Chase失踪者、Faraday数据／设备、DiMA记忆，以及保护、公开或利用真相的地方关系选择。具体地点与事件全文由世界维护，奖励信任、装备或有限人员合作。

相关组织按人物与事件表达；独立阶段维持AI避难共同体权限，铁路转型时按强制整合规则接收。居民兵源和正常补员仍可维持基本防御，追猎者制造归学院及已完成转型的铁路，独立阿卡迪亚没有制造链。

## 依赖与反制

需核学院全领主监狱控制、铁路阶段转型与强制整合，以及地下阶段无地表存续、设施发现／撤离、战后交城与合作方、安置和参战互斥、学院持续生产与能源据点、三类行动目标及修复、逃亡者归属及有限奖励。局部原型不代表整套组合通过，低成本入口仍使用原生任务／两难／设施结构，不能用普通收入城镇替代铁路隐网。

学院以Gen1廉价承线、Gen2长期主力、Gen3渗透及独立限量追猎者组织军队，具体ID唯一见兵表。制造排产复用建筑招募队列、时间与费用，技术人员承担协调；基础制造不依赖高阶监狱。铁路完成接管后取得完整生产遗产，实际建设、时间、军费、精锐容量继续有效。有限信标投送为首批战斗候选，战役传送与系统离线／恢复另列候选，均未验证组合。
