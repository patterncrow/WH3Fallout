# 尤利西斯与大分水岭

更新日期：2026-11-05。标识：F34。状态：用户确认不可玩特殊势力与四种终点选择；原型、数值及生命周期未验证。本页为独立特殊对象，不新增逻辑种族。

## 据点与军队

尤利西斯不可玩，无野战军、强驻军。曲折峡谷内四城单线相邻：霍普维尔入口→高架公路军事区→阿什顿废墟→尤利西斯神殿／导弹中枢（省会）。这是战略地理抽象，实际空间及驻军位置沿[世界设计](../../地图/战役地图设计.md)。前进目标是逐城突破而非和普通扩张AI打野战。

标记人与本地守卫为驻军用途，使用既有受损人形近战／枪械原型初设，不因此开放全地图招募链或异形生物池。尤利西斯为唯一人物，战前属于特殊驻军；和平分支才转入胜方成为传奇领主，转移后原驻军对象须清除，不能同时保留敌我两个实例。具体驻军牌数和标记人单位条目待原型选型，当前不新增成套兵表。

## 末城胜利与选择权限

胜利授予指定特性／专属装备，并进行一次四选一。完整事件、用户固定和平文本与世界目标由[世界正式事件正文](../../事件/普通事件设计.md)维护，装备和伤害效果引用[战斗正文](../../战斗/通用战斗与能力设计.md)，本页只维护归属及授予条件。

| 选择 | 结果与权限 |
| --- | --- |
| 荒漠核爆 | 指定荒漠目标转为辐射地区，获得所有其他派系好感；目标有效性由世界定义 |
| 敌对首都核爆 | 选合法敌对派系首都，目标变废墟；所有其他派系好感降低，具体关系幅度待定 |
| 原地爆破 | 末城变废墟，执行军部队覆灭；执行领主按传奇负伤／恢复方式存续并取得“核爆幸存者”，全局高质量增益及大量全派系好感；普通领主如何获得同样生命周期保障待核 |
| 和平 | 仅邮差属胜方、随胜军并处于终点区域时可选；尤利西斯加入胜方为唯一传奇领主，取得跨战斗三次战术核弹总额度，扣事件触发时当回合正收入一半 |

“核爆幸存者”含辐射损耗免疫、高额特保与近身敌军烧血光环，幅度及具体效果由战斗领域维护。原地爆破要求先保障执行领主的负伤存续，再结算整军部队覆灭，普通领主生命周期不成立时需回传限制，不能把将领永久死亡作为已满足。

和平支付按触发当回合的正收入计算，不按金库余额；非正收入时的数值处理沿世界事件定义，读取时点和资金不足处理待核。邮差须是胜方实际唯一传奇事务官实体，队友附属物、盟军邮差或仅在邻省不能代替。

## 战术核弹与人物成长

战术核弹以伊克特末日火箭为参考。三次为胜方派系跨战斗总额度，任何获授权军队使用均扣同一余量；尤利西斯负伤、换军、重招、战斗重入或同名装备不会刷新额度，不能把每军／每战三次写作实现。合法军队、使用时点与具体能力效果由共通战斗正文维护，三次总账及保存未验证。

尤利西斯个人定位初设为坚韧的混合武器统帅与有限军队支援，优先现成人形传奇领主，具体装备、技能与动作由战斗装备领域协同选型；不另授全军核爆免疫。入队归属、负伤恢复与外交任务引用须指向同一人物。邮差专项中的队友表现不得另造一份尤利西斯随从实体。

## 依赖与停点

四城驻军、胜利奖励、四选一、邮差归属及终点位置、领主转换与执行军覆灭、首都和荒漠目标、跨战斗核弹总额度、半份当回合正收入均为待验证组合。基础装备奖励、核弹效果与普通驻军原型可分别比较，但局部成立不代表整套事件完成；当前不运行验证。
