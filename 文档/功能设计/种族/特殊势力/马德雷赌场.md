# 马德雷赌场特殊据点

更新日期：2026-11-05。标识：F28。状态：用户确认特殊据点与结果；战斗、人物和建筑结算组合未验证。

## 身份与归属

以利亚控制赌场，单省唯一城、无野战军、强驻军。作为独立特殊据点，不套用异形肉食、行省四阶段、孵化、普通招募或扩张经营模板。尸鬼分类只维护幽灵人素材与引用，本页为F28唯一权限正文。位置、隔离入口、红雾损耗与完整事件见[世界设计](../../地图/战役地图设计.md)及[世界正式事件正文](../../事件/普通事件设计.md)。

## 驻军与战斗权限

| 对象 | 驻军身份及权限 |
| --- | --- |
| 以利亚 | 据点控制者与强驻军人物，技术控制／火力方向初设，具体英雄宿主待选 |
| 克里斯汀 | 唯一驻军人物，射击与观察方向初设；受维罗妮卡实际参战条件影响 |
| 迪恩 | 唯一驻军人物，守备与地区协同方向初设 |
| 狗／神 | 同一唯一人物的两种人格表现，不能配置为两份独立实体；形态宿主待核 |
| C10-U10幽灵人 | 地区专用驻军，沿选定特殊近战宿主，补充规则只服务据点 |
| C10-U11全息守卫 | 特殊驻军，无伤状态绑定城内指定发射设施；摧毁设施后才可受伤 |

人物和守军均不开放普通野战招募；该据点失守与爆炸后不向占领者赠送驻军人物或完整招募链。具体驻军牌数、装备、能力与难度待核。

维罗妮卡作为敌方实际参战，包括援军时，克里斯汀自行引爆项圈自杀并从守军移除。战斗必须能识别唯一维罗妮卡实体实际入场；战役附近、邮差附属物图标或未参战援军不满足条件。克里斯汀分支不改变最终赌场爆炸。触发时间、战斗移除及读档重入均待技术核对。

全息守卫的反制是摧毁指定发射设施，不能用普通占点或等待超时替代该条件。设施毁坏前不可受伤、毁坏后恢复可受伤的规则由[共通战斗正文](../../战斗/通用战斗与能力设计.md)维护；原生建筑破坏、实体目标与无伤状态绑定尚未验证。

## 占领后的建筑与收益

占领取得一次巨额财富后赌场爆炸，城市改名“马德雷赌场废墟”。占领军保留，已带走战利品保留。爆炸只改变指定城镇和本地建筑，不作为消灭占领军的效果。

| 对象 | 最终规则 |
| --- | --- |
| 城镇形态 | 永久唯一建筑格，其他可建设槽永久关闭 |
| 唯一建筑 | 全息玫瑰碎片，唯一、不可升级 |
| 回合收益 | 每回合仅1瓶盖；城镇本体与其他槽收益为零，税收、地标、派系或行省加成也须满足最终总额1瓶盖的目标 |
| 再开发与奖励 | 不能恢复赌场收益链或再次领取一次财富；重占与换所有者不重置事件 |

一次财富、爆炸、改名与永久槽位锁定的顺序由世界事件统一维护；财富数值待定。城镇主链、最低槽位和原生收入乘算对最终总收入的影响待技术核对。

## 叙事、唯一人物与依赖

最终爆炸弹窗固定附带用户指定的全息玫瑰叙事，无论克里斯汀分支如何均播放。该叙事只在世界正式事件正文维护，不产生指环或其他装备奖励。

维罗妮卡唯一传奇事务官归[兄弟会人物正文](../兄弟会/领主与事务官设计.md)，邮差队友不得复制第二实体。以利亚、克里斯汀、迪恩、狗／神当前只在本据点拥有一份对象，其他领域如引用同名人物须使用同一唯一身份。F28驻军不随机入异形库存。

需核：特殊驻军人物、全息发射设施破坏与无伤解除、援军实体识别、克里斯汀自杀移除、一次财富及保留军队、永久唯一格与最终1瓶盖收入。原型只比较现成驻军／战斗目标、人物状态、地标与任务结构，整套结算未验证；没有保持关键条件的低成本替代时交A收口。
