# 维加斯：建筑设计

依据：[设计总纲](../../设计总纲.md)、[种族概述](./种族概述.md)。

## 城市经营与招募链

以帝国普通城市、收入和军事建筑的结构为基础。T级是本Mod初设，不是现行原版数据库层级声明；成本、时间和普通收入优先同类原型，不自制赌场经营界面。

| 链 | 层级与内容 | 原型与建设意义 |
| --- | --- | --- |
| 主聚落：街区管理处→都市行政中心 | T1卫队U01；后续基础收入、槽位、驻军 | 普通主城／小城链，基础军不依赖机器人资源 |
| 安保营：地方武装营→雇佣战斗营→赌场安保中心 | T1枪手U02，T2冲锋U03，T3护卫U04 | 帝国普通步兵与火枪链的分层结构 |
| 雇佣联络所→专业合同所→远程训练所 | T2掮客与本地专业训练；T4狙击U05 | 普通英雄招募／高级射手链，豪斯金钱外交不以大量掮客为条件 |
| 机器人车间→火力车间 | T2巡逻U06，T4火力U07、镇压U08 | 普通机械招募链；未成立形态不作为已可招募记录 |
| 重型机库 | T5守卫U09 | 高阶构装或机械招募结构，不在每个小城建设 |
| 维修站→设备维护中心 | T2维修专家，后续容量与本地恢复；U10平台后置 | 英雄与平台不能重复赠送无限维修；机器人补员与战斗维修分别处理 |
| 商业街→赌场街→娱乐产业区 | 普通瓶盖收入，随等级成长 | 常规收入链；豪斯通过派系特性加强，不改变好好先生基本可经营性 |
| 居民服务处／秩序设施 | 分别提供增长和秩序，维持原版槽位取舍 | 不把二者合成每城必建的全能建筑 |
| 街区工事→安保防区 | 卫队、枪手、少量护卫驻军 | 不让升级自动送满高级机器人与传统城墙 |

## 供电设施与地标接口

普通发电厂采用原版资源生产建筑收支结构，提供基本电力；升级提高供电，占槽位、建设费和维护。正常规模堪用，不能低成本叠满高档奖励。负荷先归城市／机械产业，不逐队再收“数据＋电力＋零件”三份维护。收支和档位见[种族机制](./种族机制.md#电力城市与机器的经营资源)。

太阳神一号低级产电，高级可解锁阿基米德II；胡佛大坝高额供电。世界负责地标落位，不是每城通用发电链，同一大坝不在两岸重复计收益。授权、损坏、占领和转移待技术核对，炮击效果由战斗领域维护。

## 高级供给与恢复

地方军和基础巡逻机保持可靠建筑招募。U05专业射手依训练／有限池，U07／U08用车间供给或容量，U09用重型机库少量容量；U10后置。精锐稀缺与数据永久升级分开，不能升级一次就获得无限机器。主动改装和建筑直招检查同一目标限制，AI基础军无需复杂界面操作。

## 选择和权限

基层安保、收入与发展提供正常城镇循环。玩家在专业雇佣与机械设施之间投资，不需要每个聚落建齐所有军事链。智能化资源设施只在好好先生派系适用，效果与节点在其专属机制维护；不为豪斯建一条空的智能化资源链。

失去设施不抹掉既有部队或永久升级；招募资格、单位容量与状态的原型处理需技术核对。战斗维修不等于战役补员，不能把一种效果当另一种通过。
