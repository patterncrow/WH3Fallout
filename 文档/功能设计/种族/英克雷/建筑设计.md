## 基地、资料与航空设施

建筑服务于少量整备基地、高级军工和航空节点，常规城镇发展能力很弱。T级为设计目标，费用与时间采用同档原型起点；基地收入与最低重建能力为助手初设，须与战争收益及军费成套比较。

| 链 | 获取与价值 | 边界 |
| --- | --- | --- |
| 主基地 | T1 U01基础守备，后续提供整备槽位与驻军 | 保留有限发展空间；基地失守会影响招募与节点 |
| 辅助军营 | T1 U02；T2 U03、U04 | 基础军瓶盖招募，不以资料维持 |
| 装甲训练基地 | T4 U05；授权分配高级容量，建筑提供训练资格 | 不与高级科技再次重复购买同一许可 |
| 能量武器工场 | T4 U06、U07；T5 U08 | 共用动力装甲资产族，火力职责分开 |
| 地面火力工场 | T3 U09；T4 U10与对应授权容量 | 实体火箭兵的攻击与场外空援分别配置 |
| 航空设施 | 中期形成合规节点，后期U11飞行精锐资格与有限容量 | 战役移动与战斗飞行分开；早期可仅采用有限空援，不称为旋翼机通过 |
| 资料档案室 | 技术军官、必要研发与战果归档 | 不另产重复容量资源；研究费用待核 |
| 工业后勤区 | 低额瓶盖收入与省内整备建设支持 | 战争收益承担扩军及精锐军费；普通发展难以独立供养高级打击群 |
| 整备医疗区 | 省内补员、适用英雄容量 | 战役补员与战斗维修分别配置 |
| 驻防工事 | 辅助兵、有限装甲和地面火力 | 不让所有基地免费起降多支满编空军 |

U05—U08、U10、U11由部署授权分配提供高级容量，城镇所有权上限也消耗同一预算。建设军工设施只提供招募资格，不另增一份免费容量；实际换算及初始分配见机制。辅助军营可靠招募基础军。失守、解散及复建不重复领取授权，现役军保留、超额部署限制待核。

## 经营取舍

占领基地的主要价值是整备、兵源和投送节点，战斗、劫掠与毁城提供主要财政和即时资料。前期少量现役精锐配辅助军取得首批战果，中期以回收收益补齐专业兵种，后期以节点和目标选择维持战争节奏。基地的低额收入支持最低重建；战争收益、基础军费与精锐成本仍待细化，不能据此认定收支已平衡。

节点丢失、快移权限与封闭地区限制见[种族机制](./种族机制.md)。在节点宿主不确定前，这里只给建筑职责，不写虚构可运行网络或数据库键。

城市有限、多基地与高级打击群数量长期取舍，授权不能在城市与精锐重复计入。原资料回收归必要研发和任务线索，详细规则只见种族机制。
