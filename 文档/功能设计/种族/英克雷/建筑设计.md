## 基地、资料与航空设施

普通城镇可经营，军事设施偏高级军工；不要求每个据点都是可移动空中基地。T级为设计目标，费用与时间采用同档原型起点。

| 链 | 获取与价值 | 边界 |
| --- | --- | --- |
| 主基地 | T1 U01基础守备、后续收入槽位驻军 | 仍需占领和建设，不免疫普通战争 |
| 辅助军营 | T1 U02；T2 U03、U04 | 基础军瓶盖招募，不以资料维持 |
| 装甲训练基地 | T4 U05；资料许可与容量按宿主分工 | 不与高级科技再次重复购买同一许可 |
| 能量武器工场 | T4 U06、U07；T5 U08 | 共用动力装甲资产族，火力职责分开 |
| 地面火力工场 | T3 U09；T4 U10与适用资料资格 | 火箭兵不是每战额外免费空袭的来源 |
| 航空设施 | 中期形成合规节点，后期U11飞行精锐资格与有限容量 | 战役移动与战斗飞行分开；早期可仅采用有限空援，不称为旋翼机通过 |
| 资料档案室 | 技术军官、基地资料收益／适用解锁入口 | 不要求毁城资料必须先建此室才可保存；产出数值待核 |
| 工业后勤区 | 稳定瓶盖收入、省内建设支持 | 不另造零件、燃料和运输资源 |
| 整备医疗区 | 省内补员、适用英雄容量 | 不把战役恢复变成战斗无限维修 |
| 驻防工事 | 辅助兵、有限装甲和地面火力 | 不让所有基地免费起降多支满编空军 |

高级U05—U08、U10、U11的主要限制按对应资料许可＋建筑容量／专业供给设置，资料已解锁类别后不再每个普通研究重复购买。转换、合邦接收与直招检查同一目标供给；失守不删现役军，也不刷新无限高级池。辅助军营仍可直接重建普通军，AI不依赖复杂改装才可战斗。

## 经营取舍

占领基地提供长期收益和投送节点，毁城提供即时战果和资料。玩家应保留需要经营的基地，并选择破坏其他目标；不将全图所有城镇作为必须夷平的条件。

节点丢失、快移权限与封闭地区限制见[种族机制](./种族机制.md)。在节点宿主不确定前，这里只给建筑职责，不写虚构可运行网络或数据库键。
