## 当前派系差异

马德雷幽灵人和安保守军保留地区来源，不作随机孵化生物；环境狂尸鬼仅为有限低级池候选，没有合法高级生物设施时不因幽灵人设施产生高级生物。肉食、阶段库存与风暴引用[共享机制](../../../种族机制.md)。

| 项目 | 初设 |
| --- | --- |
| 人物身份 | 迪恩·多米诺为候选 |
| 一句话体验 | 封闭城区财富与特殊守卫 |
| 派系层效果候选 | 适用地标经营或幽灵人守备效果，不与所有尸鬼政治混为一体 |
| 所率军队与权限 | 指定C10-U10幽灵人和地区守军；理性尸鬼与幽灵人规则分开 |
| 首段经营与行动 | 马德雷实际城区与赌场的开局归属沿地图；原生势力无对外扩张倾向 |
| 长期方向 | 保住或争取赌场与城区经营，玩家可经特殊入口向外；不是一次性领奖副本 |
