# 塔比莎军阀集团

更新日期：2026-11-04。状态：派系差异初设0.1；移植状态见技术报告。

标识：F23。种族：[C08异形／变种人分支](../种族概述.md)。来源：已有讨论；存在形式：可玩候选。

## 概述与定位

超级变种人军阀／塔比莎等；大型、Nightkin、巨型与重火力。

## 共享内容

共享[异形核心／外围机制](../种族机制.md)，以变种人兵表为主体，不因同文化取得杰森火箭、马德雷守军或女王完整生物池。

共享[兵种](../兵种设计.md)、[人物](../领主与事务官设计.md)、[建筑](../建筑设计.md)、[科技](../科技设计.md)与[能力](../法术与能力设计.md)，按条目权限使用。

## 位置与初始关系

位置与初始关系见[战役地图设计](../../../地图/战役地图设计.md)。

## 当前派系差异

塔比莎以普通武装／枪械训练和广播指挥为主，合法战兽或高级巨型才按本省核心／设施资格进入生物池；不能用辐射孵化装备齐全的重机枪或Nightkin专业兵。肉食、阶段库存与风暴引用[共享机制](../种族机制.md)。

| 项目 | 初设 |
| --- | --- |
| 人物身份 | 塔比莎 |
| 一句话体验 | 大型战帮与广播威慑 |
| 派系层效果候选 | 普通士气、基础大型兵招募或战后收益效果 |
| 所率军队与权限 | 普通大型主体与指定火力，广播用士气技能／效果表达，不做独立电台网络 |
| 首段经营与行动 | P11辐射高台，先应对北路冲突，不能因同为变种人自动吞并雅各布斯 |
| 长期方向 | 建立地方军阀疆域，击败适合邻近威胁，不强制复制主教宗教目标 |
