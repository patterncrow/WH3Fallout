# 掠夺者AI池与归属

更新日期：2026-11-06。既有F38泛掠夺者池及地方L编号保留；共享[C05掠夺者](../种族概述.md)，按地方AI实例配置。F16大汉帮为唯一可玩，所有AI均不默认拥有其战败合邦。

| 既有标识 | 当前种族内容归属 | 少量差异／用途 |
| --- | --- | --- |
| F38 | 泛掠夺者普通AI池 | 基础近战、近程枪械和少量战兽，守备／劫掠／扩张按实例 |
| L01 | Fiends，恶魔帮 | 近程枪手与药剂爆发偏好，恢复方便但有供给上限 |
| L03 | Vipers，毒蛇帮 | 轻装枪手和伏击倾向，不新增完整毒药法系 |
| L04 | 胡狼帮 | 普通近战与机会劫掠，保留独立据点身份 |
| L05 | 大汉分支或脱离集团 | 共享主体、仍为AI候选，不增第二个可玩大汉帮 |
| L16—L20 | 锈魔、锻铁、门徒、特工、群狼 | 分别保留少量机器、喷射、近战、枪械或战兽倾向；高级数量仍有限，不全套复制F16 |
| L21的掠夺者实例 | 只有世界明确C05者适用 | 山匪与走私团按实际身份判断，不把所有L21自动视为可收编 |

L02炸药帮、L10标记人、L15枪手等仍保留原独立对象；不凭“敌对地方势力”将其全部归C05。实际世界实例文化未明确前，不作为F16战败收编的保证目标。表内归类是种族设计映射，具体出生点、实例划分和外交由世界对齐。

AI通过普通建筑和可恢复基础池招募，不需战帮／改造才能组成军队。小据点和弱帮派可提供局部胜利积累；地区重镇有独立驻军，主力与核心合防更难攻。低扩张者仍能防守和重建，生命力来自普通兵源与残存地盘，不靠无限刷新或无条件复国。特性和精确强度待原型定位，不新增各帮完整科技、资源或兵表。

表内全部C05实例（含F16）作为宣战目标均适用[完全信用豁免](../种族机制.md#对掠夺者宣战的信用豁免)，包括条约／刚签约／同盟附庸等全部条件。实际目标种族必须明确，叛乱或改属后的文化归类由技术核对；不自动把未归C05的地方对象纳入。其他帮派只用自己的有限兵源与药剂倾向，不共有草原主部、派遣队和完整配方。
