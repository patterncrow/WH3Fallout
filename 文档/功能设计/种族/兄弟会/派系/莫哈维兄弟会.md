## 当前派系差异

共享知识资源与军械整备，普通城市交明面代理，受限直辖核心提供招募和精锐容量。麦克纳马拉偏修复守备，哈丁偏有限远征，均不能靠升级绕容量；具体规则见[种族机制](../种族机制.md)。

| 项目 | 初设 |
| --- | --- |
| 人物身份 | 麦克纳马拉 |
| 一句话体验 | 强人物、岗位与有限精锐 |
| 派系层效果候选 | 军事设施整备、知识修复或有限精锐维持的现成效果，具体择项初设 |
| 所率军队与权限 | 所率辅助军、骑士和防御支援；不是所有军队永久免疫损耗 |
| 首段经营与行动 | P02隐蔽山堡，先建立有限基础兵补充和初期精锐容量，再争取技术据点；不要求开局击败同省大汉帮 |
| 长期方向 | 控制关键技术据点并消除主要威胁，保住核心堡垒；玩家仍可远征 |
