# 莫哈维兄弟会

更新日期：2026-11-10。状态：派系差异初设0.1；移植状态见技术报告。

标识：F12。种族：[兄弟会](../种族概述.md)。来源：已有讨论；存在形式：本种族唯一可玩派系。

## 位置与初始关系

位置与初始关系见[战役地图设计](../../../地图/战役地图设计.md)。

## 当前派系差异

共享知识资源与军械整备，普通城市交明面代理，受限直辖核心提供招募和精锐容量。麦克纳马拉偏修复守备，哈丁偏有限远征，均不能靠升级绕容量；具体规则见[种族机制](../种族机制.md)。

| 项目 | 初设 |
| --- | --- |
| 人物身份 | 麦克纳马拉 |
| 一句话体验 | 强人物、岗位与有限精锐 |
| 派系层效果候选 | 军事设施整备、知识修复或有限精锐维持的现成效果，具体择项初设 |
| 所率军队与权限 | 所率辅助军、骑士和防御支援；不是所有军队永久免疫损耗 |
| 首段经营与行动 | P02隐蔽山堡，先建立有限基础兵补充和初期精锐容量，再争取技术据点；不要求开局击败同省大汉帮 |
| 长期方向 | 沿本族共享胜利目标，以本派特色军队与经营方式推进 |

## 原型与边界

特性数值、起始兵力、能力参数及人物资产待细化；派系与领主效果按上表分开。

## 胜利目标

采用[本族共享胜利目标](../种族概述.md#目标与成长)。普通派系按扩张、同族整合与战争结算；特色转型沿本族机制，具体计数由助手配置，未验证实现。

## 军队与经营成长

附近适中难度任务提供首段经验与回收奖励，现有核心设施可恢复首批精锐；资料任务可指向大势力城镇，玩家可放弃或承担战争。太阳神一号提供专属全局军费／整备／资源成长转折，地标高阶轨道炮独立授权。

## 军队成长工作样本

初设与结算沿[共通工作口径](../../../设计总纲.md#工作样本的共通计价与成长口径)，起点／外交沿世界正文。初始可用瓶盖6000，正常维护与建设均需实际支付。

| 阶段 | 可用军队与行动 |

| 特色转折 | 逐步建代理网络及夺回堡垒岗位；光复太阳神一号初设全局军费−10%、知识收益+15%、本省整备补员+3个百分点，高阶轨道炮独立。 |
| 中后期代表军 | 1领主＋2英雄＋2 U01＋3 U02＋5 U05＋2 U06＋2 U07＋1 U04（18牌）；补足容量后仍以精英核心配辅助军。 |
