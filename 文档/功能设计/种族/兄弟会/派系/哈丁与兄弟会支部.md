## 概述与定位

哈丁及各地兄弟会支部共享种族主体。普通支部由大众脸领主驻守隐藏堡垒，差异主要来自位置、初始设施、驻军与当地回收目标；哈丁保留既有人物及个人方向。

## 当前派系差异

共享知识资源与军械整备，普通城市交明面代理，受限直辖核心提供招募和精锐容量。麦克纳马拉偏修复守备，哈丁偏有限远征，均不能靠升级绕容量；具体规则见[种族机制](../种族机制.md)。

| 项目 | 初设 |
| --- | --- |
| 人物身份 | 哈丁为既有人物候选 |
| 一句话体验 | 有限精锐远征 |
| 派系层效果候选 | 精锐招募训练或适用远征维持效果，不增加无限容量 |
| 所率军队与权限 | 所率U06—U08精锐与战果，仍依赖本族军事设施容量 |
| 首段经营与行动 | 守住所属隐藏堡垒与回收路线，先保证后方和一支可维护的远征军；位置与邻接引用世界正文 |
| 长期方向 | 围绕所在地区形成据点优势并击败直接威胁，保持共享的AI低扩张倾向 |
