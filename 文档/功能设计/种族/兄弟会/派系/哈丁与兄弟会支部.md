更新日期：2026-11-06。状态：派系差异初设0.1；移植状态见技术报告。

## 当前派系差异

共享知识资源与军械整备，普通城市交明面代理，受限直辖核心提供招募和精锐容量。麦克纳马拉偏修复守备，哈丁偏有限远征，均不能靠升级绕容量；具体规则见[种族机制](../种族机制.md)。

| 项目 | 初设 |
| --- | --- |
| 人物身份 | 哈丁为既有人物候选 |
| 一句话体验 | 有限精锐远征 |
| 派系层效果候选 | 精锐招募训练或适用远征维持效果，不增加无限容量 |
| 所率军队与权限 | 所率U06—U08精锐与战果，仍依赖本族军事设施容量 |
| 首段经营与行动 | P18山堡分部，面对英克雷／技术走廊压力，先保证后方和一支可维护的远征军 |
| 长期方向 | 在技术走廊形成据点优势并击败直接威胁；不因此改变全文化AI低扩张基调 |

## 原型与边界

特性数值、起始兵力、能力参数及人物资产待细化；派系与领主效果按上表分开。
