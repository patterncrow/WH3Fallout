## 堡垒建设与招募对应

以普通城镇建筑为主体，军事等级和驻军偏矮人防守结构；容量取古墓王建筑提供单位配额。T级为Mod初设，不是现行数据记录。

| 链 | 招募或效果 | 投入与原型边界 |
| --- | --- | --- |
| 主堡垒 | T1 U01辅助承线，后续基础驻军与槽位 | 普通聚落结构，不因隐蔽就免受围攻 |
| 辅助军营 | T1 U02、U03；T2 U04侦察 | 普通火枪、手枪与专业射手招募，完整基础军不被容量锁死 |
| 骑士军校 | T3 U05；T4 U06与其容量 | 常规专业枪兵到精锐近战，保留低阶兵必要性 |
| 能量武器工房 | T4 U07与容量，T5 U08与容量 | 高级火力路线；不同兵种按原生可用容量结构分别计数 |
| 防御火炮间 | T3 U09 | 帝国迫击炮职责，驻防与野战炮招募分别记录 |
| 技术维修室／恢复工坊 | T2技术学士，后续人物容量、省内恢复及知识项目入口；U10平台后置 | 参考伊克特工坊／矮人工坊的指定升级入口，未验证；战斗维修、战役补员和装备修复分开 |
| 地堡维护区 | 增长与建设支援 | 常规增长链，不自动另造深隧空间；深隧保留给完整避难所专项 |
| 工业供给区 | 稳定瓶盖收入 | 无技术资源日常物流 |
| 指挥与纪律设施 | 地方秩序、适用人物训练 | 不为保守风格添加复杂内部选举 |
| 堡垒防区 | 辅助守备、少量专业骑士，较高层级增加有限精锐 | 驻军和场景独立配置，不宣称建设升级必有城墙 |

知识来源与项目只见[种族机制](./种族机制.md#知识与工坊恢复修复路线)。技术据点和修复设施提供适用知识，不另建重复材料产业；建筑仍提供常规招募和精锐容量。U05→U07换装与建筑招募共享同一目标容量，不让晋升绕过限额；工坊不同时兼任免费精锐生产和无限医疗。

## 选择与恢复

精锐工房和容量增长争夺资金与槽位，不要求把所有城都变成全精锐生产中心。玩家可以先造辅助军远征，也可以集中投入主堡垒。容量数值以原型起点核对后定，不用一个未经观察的固定数宣称平衡成立。

损坏、拆除、失城与超额按容量宿主处理。堡垒伪装不改变正常占领权与经营对象；不能把整个兄弟会改成只能在地下附着的地下帝国。
