## 前置与作用对象

每条分支内部按箭头顺序前置，分支间不普遍互锁。精确节点名称沿既有主题；效果优先同类原版科技，幅度和时间待数据定位。

| 既有分支 | 本轮明确的对象与边界 |
| --- | --- |
| 枪手训练→移动射击训练→散兵协同 | U02、U03基础枪兵训练；U07、U08采用原型已有骑射表现；U02、U07弹药或装填择一。不能用科技把所有步枪变成移动射击。 |
| 药剂适应→突击纪律→老兵战术 | U04爆发、U10近战训练与防守分别取现成狂战士／轻步兵科技效果，不同时给永久全属性强化。 |
| 营地扩建→地方交易→部落组织 | 普通建设成本、收入、秩序或基础军维护，采用普通城镇科技，不建第三资源。 |
| 骑乘训练→战车保养→机动围猎 | U07、U08训练与维护，U09原型成立后加入；最后选指定机动单位冲锋或弹药，不兼得重骑全部优势。 |

建筑负责招募资格，科技负责强化，人物红线负责所率军队。没有具体效果记录时保持初设，不把类别建议当作已定位表键。
