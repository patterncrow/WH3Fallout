# 大可汗：建筑设计

更新日期：2026-11-02。状态：共享经营与原型边界初设0.1；建筑层级是本Mod设计目标，不是已定位的原版记录。已确认原则优先，数值和适配不冒充通过。

依据：[设计总纲](../../设计总纲.md)、[种族概述](./种族概述.md)。

## 建设定位

沿普通地方城镇与军事建筑结构，以骑乘和轻装专业兵的选择形成差异，不需要专属药品经济或商队系统。手枪骑兵与先驱侍骑采用帝国骑射职责；骑乘原型行为不允许给所有步行枪手凭空加移动射击。

| 链 | 层级与招募初设 | 取舍 |
| --- | --- | --- |
| 营地主聚落 | T1 U01营地战士 | 普通驻军与槽位，收入不依赖掠夺才存在 |
| 武装营 | T1 U02近程枪手；T2 U03步枪与U04药剂突击；T4 U10老兵 | 常规射击、近战和狂战士原型结构；药物不成为新货币 |
| 荒野哨所 | T1 U06郊狼；T2猎手／荒野斥候；T4 U05荒野猎手 | 专业观察与伏击投资，不送全军永久潜行 |
| 骑乘营 | T2 U07手枪骑兵；T4 U08长枪骑手 | 帝国马厩式层级；不因为“长枪”就同时变近战重骑 |
| 战车工坊 | T4 U09劫掠战车 | 最后确定一个远程战车宿主后制作，不是自由驾驶载具 |
| 药剂师营帐 | T2药剂师、后续适用英雄容量和省内恢复 | 恢复与爆发技能择主用途，不新造生产配方 |
| 地方贸易、居民营地、首领议事营、营垒 | 分别为收入、增长、秩序、驻军 | 沿原版独立槽位选择，避免一个营帐提供全部民用效果 |

## 兵种原型补充

U01比较诺斯卡掠夺者；U02自由民兵；U03帝国火枪手；U04诺斯卡狂战士；U05人形步枪与猎手部署职责组合；U06战獒；U07帝国手枪骑兵；U08帝国先驱侍骑；U09具体远程战车待选；U10精锐轻装人形近战待选。原型不是全部动作已适配的声明。

普通招募用瓶盖，成长靠设施、科技与人物；阵地硬攻与重甲火力是短板。科技与人物依既有主题逐项选原版效果，不能为追求文化规模扩出重炮和空军。


精确层级、费用、研究与单位属性优先从已选原型核对；本轮没有构建、测试或游戏操作。
