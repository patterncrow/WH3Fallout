# 聚落：建筑、驻地与招募

更新日期：2026-11-04。状态：用户确认方向；具体条目、角色与原型组合为助手初设，未验证移植。依据：[设计总纲](../../设计总纲.md)。技术依赖统一引用[技术集中待验证项](../../../可行性验证/首批可行性验证方案.md#十当前设计组合待验证清单)。

| 设施 | 普通聚落／代理城镇 | F35／F32差异 |
| --- | --- | --- |
| 小城主链与地方产业 | 基础收入、发展、有限U01／U02驻军；普通聚落不升成完整军事大城 | F35直属核心允许必要军事建设；F32核心可建专属炮兵与工事 |
| 防御序列 | 工事、密封掩体／过滤等本地区辐射防护，范围引用世界；驻军依投入有限成长 | 大炮族基地坚固，义勇军驻地只补实际缺口，不每个小城都变堡垒 |
| 义勇军地下驻地／民兵指挥部 | 代理持有城镇中F35的特殊附属设施目标，不取代地表所有权 | 防御／驻军／训练选择明确用途，权限与失守继承待核 |
| 专业训练 | 普通聚落不开野战招募；代理可靠基础守备 | F35有限U03；F32炮厂提供U04／U05，不向全文化开放 |

村镇加入同盟国后由F41发展，F35仅接收约定收入及合法驻地操作。指挥官效果不再复制同一建筑链和同一驻军，建设／修复有时间及费用。直属核心名额不因移交、反复占领／转让增加。跨附庸驻地与委派只作为目标，集中清单记录未知。
