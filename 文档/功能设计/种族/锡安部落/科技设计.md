## 前置与作用对象

每条分支内部按箭头顺序前置，分支间不普遍互锁。精确节点名称沿既有主题；效果优先同类原版科技，幅度和时间待数据定位。

| 既有分支 | 本轮明确的对象与边界 |
| --- | --- |
| 猎战传统→伏击配合→峡谷作战 | U03弓手训练、U05轻装伏击单位表现、指定步兵的适用防守；不等于全军永久潜行或无视地形。 |
| 矛盾配合→精锐勇士→部落军阵 | U02反大型承线、U06近战输出、U09守备，按原版相应兵组效果，不重造战阵系统。 |
| 聚落修缮→共同储备→部落组织 | 普通建设、增长或补员、地方治理。无独立食物和生存物资。 |
| 野地医疗→武器维护→枪械训练 | 战役补员、U04弹药或维护、U08训练。部落权限仍由派系／建筑决定，研究不自动统一三部落兵表；U08资格来自选定试炼／建筑分工，不重复加研究许可。 |

公共研究偏U01—U03基础兵训练、普通补充和经营，不普遍涨维护。高级资格主要由适用试炼提供，研究只强化合法对象，不叠成无反制全属性精锐。

建筑负责招募资格，科技负责强化，人物红线负责所率军队。没有具体效果记录时保持初设，不把类别建议当作已定位表键。
