# 邮差传奇事务官设计

版本：功能工作稿0.3（2026-10-31）。依据：[项目概念设计](../../项目概念设计.md)、[设计对比表SYS31—SYS32](../原版参考/战锤设计对比参考表.md)。用户确定的方向是约束；本稿任务、预算、流程与效果为助手执行方案，尚未游戏内验证。

## 一、角色与构筑边界

邮差是强力传奇事务官，不统军。相关派系通过任务招募，有SPECIAL、Trait天赋、Perk、专属装备和原作队友随从。邮差不使用战旗；军团与超级变种人等是否有战旗不受影响。

当前工作预算选择：**一种武器路线、至多两个Trait、三个关键Perk选择机会**。这是助手采用的设计版本，不冒充用户指定的数量。满级、重置、重招或更换归属也不能增加这些名额，不能用装备暗中补齐另一条武器路线。

沿用英雄等级、技能点和装备结构，不做实时VATS、自制RPG属性面板、战中切职业和独立队友小队控制。

## 二、招募流程与唯一性

仅考虑单人。首批资格覆盖NCR、军团、豪斯、好好先生、兄弟会、大可汗及格雷厄姆相关集团的玩家开局；其他派系未来按内容相关性扩充，不把“中国背景素材储备”等当可玩开局。初设只向合资格玩家发放招募任务，不设计AI抢先刷任务夺走唯一人物；AI模式不是本轮必须项。

| 阶段 | 任务／交互 | 结果 |
| --- | --- | --- |
| 接触 | “未送达的包裹”：玩家进入主要交通区或完成初始军事任务后收到线索 | 打开共享任务主干，文本按派系换皮 |
| 委托 | 完成一次针对邻近敌军／地点的正常任务 | 取得委托资格，不重复制作多个完整剧情 |
| 定型 | “这次带什么家伙”：四选一武器路线 | 记录选择，选完后才创建对应英雄变体，避免先生成再迁移技能 |
| 加入 | 创建邮差、配发路线初级专属武器与基本防具 | 同一战役唯一实例，归玩家所有 |
| 天赋 | 两次独立天赋事件，各有三个不同候选及放弃选项 | 至多两个Trait，不先发满六个再要求自觉少用 |
| 历练 | 完成三项阶段委托 | 每项提供一次Perk三选一机会 |
| 装备成长 | 完成路线任务、筹码任务与队友任务 | 同路线武器升级、白金筹码及随从，奖励分别记录 |

没有固定期限自动离队。已出现的邮差不会因为新派系满足条件再复制。玩家尚未完成武器选择时任务可以保留，但不先发一名可操作的通用邮差。

## 三、四条武器路线

每条先选一个技术可用的人物原型与一种标志武器。名称为主题，不声称列出的专属变体都出自原作；专属型号可由项目原创。

| 路线 | 专属武器与原型方向 | 主要战场价值 | 明确保留的弱点 |
| --- | --- | --- | --- |
| 潜行狙击 | 反器材步枪主题；精准射击英雄，保留兼容的举枪与射击动作 | 隐蔽部署、点杀大型或重要目标 | 射界、装填与近战接敌，不兼任持续范围清兵 |
| 大兵 | 军用自动步枪主题；持续射击英雄原型 | 中程持续输出、正面作战 | 单发狙杀与潜行不同时达到最高水平 |
| 牛仔 | 左轮主题；合适手枪射击英雄 | 中近程高效射击与机动 | 射程、弹药或装填取舍，不同时配杠杆枪另一套动作 |
| 近战 | 双手重锤主题；现成重武器英雄 | 接敌、破甲与近战生存 | 无常驻狙击火力，靠走位和少量能力接近 |

近战初设选择重锤，是为优先适配现成动作；动力拳套等继续作为替换候选，不在一条路线同时制作所有武器。若该方向与可用资产不符，比较兼容原型后调整具体武器，不改变四条互斥路线的设计要求。

每条路线设基础与强化两阶段武器，升级替换旧版本，不累积多把同时生效的专属武器。共享装备可以强化当前路线，但不能解锁另一变体、另一射击模式或第二套核心专精。

## 四、SPECIAL技能主题

| 主题 | 节点方向 | 主要对象 |
| --- | --- | --- |
| S力量 | 近战攻击、伤害与重武器适应 | 本人；远程路线只取有意义节点 |
| P感知 | 射击、侦察与目标辨识 | 本人／适用观察效果 |
| E耐力 | 生命、防护、辐射耐受 | 本人；损耗范围另核 |
| C魅力 | 鼓舞与同伴协作 | 有限嵌入／光环，不复制领主完整红线 |
| I智力 | 医疗、装置与专业行动 | 本人能力与适用支援 |
| A敏捷 | 装填、机动与潜行 | 具体合法效果由原型确认 |
| L幸运 | 危急保命与特殊攻击能力 | 既有被动／主动，不造通用暴击系统 |

七主题组织普通技能树，具体等级、节点数和投入必须以目标英雄的真实点数预算为依据，不能凭空填写最大等级。设计目标是重要节点有取舍，Trait与Perk的硬名额则由独立选择记录限制，不能仅靠暂时技能点不足。

武器路线只显示或启用适配内容，不能近战邮差点完一条线就长出未制作的步枪射击。技能重置不重置武器、天赋与Perk的永久选择。

## 五、Trait：两次选择，保留正负取舍

按事件永久选择为主路线，不同时复制符文锻造与互斥技能两套界面。每次三个候选加“保持原样”，放弃不带惩罚，也不把未用名额留给无限重复事件。

| 阶段 | 候选天赋主题 | 本Mod取舍方向 |
| --- | --- | --- |
| 第一次 | 快枪手 | 远程射击节奏更快，精度／单发效率付出代价；近战路线不出现无效射击选项 |
| 第一次 | 沉着射手 | 精准与单发效率，射击节奏较慢；近战路线改为同主题稳重打击候选 |
| 第一次 | 好脾气 | 支援或行动更强，个人杀伤有代价 |
| 第二次 | 重装倾向 | 生存／防护更强，移动有代价 |
| 第二次 | 小个子 | 机动或隐蔽倾向，生命／承伤付出代价；不动态改变碰撞体积 |
| 第二次 | 熟练 | 专业行动／设备效果更强，成长效率或另一项能力有代价 |

名称中部分为原作主题、部分为项目改编标签，不伪称其效果与新维加斯原公式一致。每条路线保证每次至少有多个有效候选；不用“只有唯一可用选项”假装有构筑选择。

天赋在技术上可用普通特性、效果或专属附属物表达，但选择记录为权威。没有可靠去除旧效果的路径前不开放重选，不允许不断拆装留下全部效果。

## 六、Perk：三次委托，各选一项

采用任务完成后事件三选一的主路线。阶段任务按正常行动和战斗组织，不为每个Perk做任务战地图。以下名字用于辐射风格，Mod效果按战锤原型改编，正式中文名再统一。

| 阶段 | 候选池 | 初设作用 |
| --- | --- | --- |
| 第一阶段：武器历练 | 狙击路线：狙击手／集中火力／快速装填；大兵：突击队员／快速装填／坚韧；牛仔：牛仔／快速装填／专业人士；近战：忍者／穿刺打击／杀戮者主题 | 三种不同攻击或生存倾向，依当前路线给有效效果 |
| 第二阶段：废土生存 | 坚韧／轻装快步／原子之子主题 | 承伤、机动、适用辐射条件三选一；已有同主题时替换等效候选，避免重复无效选择 |
| 第三阶段：传奇委托 | 神秘陌生人／死神冲刺／血肉横飞 | 有限特殊支援、战斗恢复／机动、个人杀伤三选一；不制作VATS或新肢解系统 |

Perk可附带被动或绑定能力，但只领取一项，未选项不出现在后续普通技能里补买。三阶段不必依次给全路线同一种加成，兼顾不同构筑。

神秘陌生人的首批表达为有限特殊攻击／支援能力，不自动增加一个常驻可操作英雄；若原型不合适，可调整表现，不改变少量终点互斥的原则。

## 七、装备、白金筹码与队友随从

| 装备位置／主题 | 功能选择 | 边界 |
| --- | --- | --- |
| 唯一路线武器 | 基础→强化 | 旧版替换，其他路线武器不给领取 |
| 防具 | 游骑兵装甲或信使风衣主题 | 通过不同数值适配路线，不反向要求全部新动画 |
| 技术装置 | Pip-Boy／隐身小子主题 | 有限能力或专业效果，不能全路线常驻隐身 |
| 白金筹码 | 独立任务的专属非武器装备，优先护符／附魔物品类可用槽位 | 先给任务／技术支援方向，不解锁第二武器，不作为好好先生数据库存 |
| 队友随从 | 通过任务取得，使用原版附属物槽位与限制 | 不同队友的效果按适用范围配置，不为八个队友新建战场实体 |

| 队友 | 随从作用方向 |
| --- | --- |
| 布恩 | 射击与观察 |
| Cass | 行动与适用维持／交易帮助 |
| 维罗妮卡 | 近战与装备支援 |
| 阿凯德 | 医疗与技术 |
| 劳尔 | 维修与维持 |
| 莉莉 | 隐蔽与近战 |
| ED-E | 侦察与射击辅助 |
| Rex | 侦察与追踪 |

本轮执行选择：上述八名人物先统一作为邮差随从素材，不同时制作互不关联的独立同名英雄。兄弟会等角色池中维罗妮卡“可独立英雄”暂缓。队友随从实际可装数量与类型限制须先核对原版槽位，不默认八个能同时装，也不为复刻RPG两人小队而新增界面。无效叠加、他人装备权限与转移按具体附属物原型明确。

## 八、生命周期与持久状态

| 情形 | 功能处理方案 |
| --- | --- |
| 尚未招募 | 全局唯一实例不存在；任务状态可持续，不重复创建 |
| 创建完成 | 保存唯一身份、玩家归属、武器路线、已领装备与选择记录 |
| 受伤 | 按传奇英雄返回原型处理，返回后保留已选路线和名额 |
| 真正永久失去 | 不重新赠送一套全新构筑；是否能重现按目标宿主支持情况决定，不能用新人物重复领奖 |
| 解散／重招 | 不重开招募奖励、Trait与Perk事件；复制奖励必须被阻止 |
| 玩家合邦取得人物 | 保留人物已有选择与物品；不根据新派系重发任务 |
| 归属派系灭亡 | 先采用宿主合法返回／移除行为；跨派系重新出现若无法保留完整状态，则列技术阻塞，不静默刷新角色 |
| 普通技能重置 | 只重置可重置技能；永久构筑选择不变，旧效果不能残留叠加 |
| 保存载入 | 记录与实际人物核对，不把任务回调重入当第二次选择机会 |

首版不开放武器路线重选和Trait／Perk重配，避免为方便而开发整套状态迁移。未来若扩展必须先有可靠撤销效果与物品的技术路线。

## 九、实施级设计的未决输入

本轮已在AK中定位菲利克斯、高崔克英雄子类型和技能两难／锁定关系，具体键只在[技术概要第十节](../技术设计/技术概要设计.md)维护。四类武器动作的实际适配、装备槽位、返回行为、任务脚本与运行包交叉核对仍未完成，不能据这些静态字段生成完整实施包。主路线已选“生成前定武器＋事件有限选择”，尚未验证其全部技术组合；每种子类型cap=1不等于四变体共同唯一，仍须共享获取约束。

人物唯一、事件名额、装备升级与存档记录可独立准备，但不能在未有目标数据时先写全套猜测脚本。当前未运行游戏、修改资源或执行测试。
