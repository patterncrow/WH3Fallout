# 邮差传奇事务官设计

状态：功能初设（更新日期：2026-11-06）。依据：[项目概念设计](../../项目概念设计.md)、[设计对比表SYS31—SYS32](../原版参考/战锤设计对比参考表.md)。用户确定的方向是约束；本稿任务、预算、流程与效果为助手执行方案，尚未游戏内验证。

文档职责：跨种族传奇事务官专项，邮差的获取、构筑、装备、队友获取与生命周期在本文唯一维护；各种族和派系只引用相关权限与差异。共用模板与推进方式见[设计总纲](./设计总纲.md)。

## 一、角色与构筑边界

邮差是强力传奇事务官，不统军。相关派系通过任务招募，有SPECIAL、Trait天赋、Perk、专属装备和原作队友任务链。邮差不使用战旗。

初设预算：**一种武器路线、至多两个Trait、三个关键Perk选择机会**。满级、重置、重招或更换归属也不能增加这些名额，不能用装备暗中补齐另一条武器路线。

构筑采用英雄等级、技能点、事件选择与原版装备结构。

## 二、招募流程与唯一性

仅考虑单人。首批资格覆盖NCR、军团、豪斯、好好先生、兄弟会、大汉帮F16及格雷厄姆相关集团的玩家开局。任务仅发给合资格玩家。学院与铁路可玩，阿卡迪亚为AI；学院／铁路及义勇军的邮差获取资格尚待种族与世界协商，可玩身份不自动扩充本专项资格清单。

| 阶段 | 任务／交互 | 结果 |
| --- | --- | --- |
| 接触 | “未送达的包裹”：玩家进入主要交通区或完成初始军事任务后收到线索 | 打开共享任务主干，文本按派系换皮 |
| 委托 | 完成一次针对邻近敌军／地点的正常任务 | 取得委托资格，不重复制作多个完整剧情 |
| 定型 | “这次带什么家伙”：四选一武器路线 | 记录选择，选完后才创建对应英雄变体，避免先生成再迁移技能 |
| 加入 | 创建邮差、配发路线初级专属武器与基本防具 | 同一战役唯一实例，归玩家所有 |
| 天赋 | 两次独立天赋事件，各有三个不同候选及放弃选项 | 至多两个Trait |
| 历练 | 完成三项阶段委托 | 每项提供一次Perk三选一机会 |
| 装备成长 | 完成路线任务与筹码任务 | 同路线武器升级与白金筹码，奖励分别记录 |
| 队友接触 | 邮差加入后开启各队友任务 | 人形伙伴逐人加入为唯一传奇事务官，ED-E／Rex取得随从奖励，见第七节 |

没有固定期限自动离队。已出现的邮差不会因为新派系满足条件再复制。玩家尚未完成武器选择时任务可以保留，但不先发一名可操作的通用邮差。

### 2.1 好好先生初始邮差

好好先生开局拥有唯一邮差，初军较少的具体编成由种族维护。开局邮差登记为已招募，接触与委托阶段标为已完成，奖励去重记录同步建立，队友任务链正常开启；其他合资格派系仍按任务流程获取同一全局实例。世界已有邮差时，各入口读取该人物与归属，不再创建第二人。

四选一武器与永久选择预算照常执行。助手初设把武器选择前置为新战役初始化事件，在首次可操作前按所选变体配置该开局人物；Trait、Perk及装备成长沿后续任务领取。初始化人物、武器选择、存档与奖励记录如何原子衔接待技术核对，不能用重复招募补齐状态。好好先生开局拥有邮差只开启队友任务，各伙伴仍逐项满足任务与外交条件；布恩对NCR、维罗妮卡对兄弟会的永久离队规则继续适用。

### 2.2 大分水岭和平资格

大分水岭末城胜利后的四选一事件中，和平选项要求邮差归胜方所有，并随胜军处于终点区域。初设按事件结算时的邮差唯一身份、当前归属、存续状态及随军位置共同判定；单独站在其他地区、未归胜方或尚未返回的邮差不满足条件。援军随胜军进入终点后的资格映射、战斗胜利到事件弹出之间的移动／受伤处理由世界与技术核对，不能仅以派系曾经招募邮差代替当前条件。

和平分支给予胜方尤利西斯传奇领主及全派系跨战斗三次总A13额度，扣事件触发时当回合正收入的一半。收入取值、取整及实际扣款由世界事件定义，邮差路线、Trait／Perk与队友奖励不重置。事件全文在[普通事件正文](./事件/普通事件设计.md)唯一维护，逐字采用用户指定文本；战斗库存规则见[共通6.9](./战斗/通用战斗与能力设计.md#69-特殊守城传奇人物与有限战略奖励)。

马德雷维罗妮卡触发克里斯汀自杀的条件只看维罗妮卡在敌对一侧实际参战，含援军入场；和邮差终点和平资格是两项独立判定。马德雷爆炸后的固定玫瑰叙事由世界维护，所有克里斯汀分支均保留该文本，戒指不作为邮差装备奖励。

## 三、四条武器路线

每条路线选一个可用人物原型与一种标志武器，专属型号可采用项目原创。

| 路线 | 专属武器与原型方向 | 主要战场价值 | 明确保留的弱点 |
| --- | --- | --- | --- |
| 潜行狙击 | 反器材步枪主题；精准射击英雄，保留兼容的举枪与射击动作 | 隐蔽部署、点杀大型或重要目标 | 射界、装填与近战接敌，不兼任持续范围清兵 |
| 大兵 | 军用自动步枪主题；持续射击英雄原型 | 中程持续输出、正面作战 | 单发狙杀与潜行不同时达到最高水平 |
| 牛仔 | 左轮主题；合适手枪射击英雄 | 中近程高效射击与机动 | 射程、弹药或装填取舍，不同时配杠杆枪另一套动作 |
| 近战 | 双手重锤主题；现成重武器英雄 | 接敌、破甲与近战生存 | 无常驻狙击火力，靠走位和少量能力接近 |

近战初设选择重锤，是为优先适配现成动作；动力拳套等继续作为替换候选，不在一条路线同时制作所有武器。若该方向与可用资产不符，比较兼容原型后调整具体武器，不改变四条互斥路线的设计要求。

每条路线设基础与强化两阶段武器，升级替换旧版本，不累积多把同时生效的专属武器。共享装备可以强化当前路线，但不能解锁另一变体、另一射击模式或第二套核心专精。

## 四、SPECIAL技能主题

| 主题 | 节点方向 | 主要对象 |
| --- | --- | --- |
| S力量 | 近战攻击、伤害与重武器适应 | 本人；远程路线只取有意义节点 |
| P感知 | 射击、侦察与目标辨识 | 本人／适用观察效果 |
| E耐力 | 生命、防护、辐射耐受 | 本人；损耗范围另核 |
| C魅力 | 鼓舞与同伴协作 | 有限嵌入／光环，不复制领主完整红线 |
| I智力 | 医疗、装置与专业行动 | 本人能力与适用支援 |
| A敏捷 | 装填、机动与潜行 | 具体合法效果由原型确认 |
| L幸运 | 危急保命与特殊攻击能力 | 既有被动／主动，不造通用暴击系统 |

七主题组织普通技能树，等级、节点数与投入按目标英雄的实际点数预算确定。设计目标是重要节点有取舍，Trait与Perk的硬名额则由独立选择记录限制，不能仅靠暂时技能点不足。

武器路线只显示和启用适配的技能与动作。技能重置不重置武器、天赋与Perk的永久选择。

## 五、Trait：两次选择，保留正负取舍

Trait采用事件永久选择。每次三个候选加“保持原样”，放弃不带惩罚，也不把未用名额留给无限重复事件。

| 阶段 | 候选天赋主题 | 本Mod取舍方向 |
| --- | --- | --- |
| 第一次 | 快枪手 | 远程射击节奏更快，精度／单发效率付出代价；近战路线不出现无效射击选项 |
| 第一次 | 沉着射手 | 精准与单发效率，射击节奏较慢；近战路线改为同主题稳重打击候选 |
| 第一次 | 好脾气 | 支援或行动更强，个人杀伤有代价 |
| 第二次 | 重装倾向 | 生存／防护更强，移动有代价 |
| 第二次 | 小个子 | 机动或隐蔽倾向，生命／承伤付出代价；不动态改变碰撞体积 |
| 第二次 | 熟练 | 专业行动／设备效果更强，成长效率或另一项能力有代价 |

Trait名称采用原作主题与项目改编标签，效果按战锤原型配置；每条路线每次提供多个有效候选。

天赋在技术上可用普通特性、效果或专属附属物表达，但选择记录为权威。没有可靠去除旧效果的路径前不开放重选，不允许不断拆装留下全部效果。

## 六、Perk：三次委托，各选一项

采用任务完成后事件三选一的主路线。阶段任务按正常行动与战斗组织。以下名字用于辐射风格，Mod效果按战锤原型改编，正式中文名再统一。

| 阶段 | 候选池 | 初设作用 |
| --- | --- | --- |
| 第一阶段：武器历练 | 狙击路线：狙击手／集中火力／快速装填；大兵：突击队员／快速装填／坚韧；牛仔：牛仔／快速装填／专业人士；近战：忍者／穿刺打击／杀戮者主题 | 三种不同攻击或生存倾向，依当前路线给有效效果 |
| 第二阶段：废土生存 | 坚韧／轻装快步／原子之子主题 | 承伤、机动、适用辐射条件三选一；已有同主题时替换等效候选，避免重复无效选择 |
| 第三阶段：传奇委托 | 神秘陌生人／死神冲刺／血肉横飞 | 有限特殊支援、战斗恢复／机动、个人杀伤三选一；不制作VATS或新肢解系统 |

Perk可附带被动或绑定能力，但只领取一项，未选项不出现在后续普通技能里补买。各阶段候选兼顾不同构筑。

神秘陌生人的首批表达为有限特殊攻击／支援能力，不自动增加一个常驻可操作英雄；若原型不合适，可调整表现，不改变少量终点互斥的原则。

## 七、装备与队友任务链

### 7.1 邮差装备与机械伙伴随从

| 装备位置／主题 | 功能选择 | 边界 |
| --- | --- | --- |
| 唯一路线武器 | 基础→强化 | 同路线替换，其他路线武器不给领取 |
| 防具 | 游骑兵装甲或信使风衣主题 | 通过属性适配路线，动作沿宿主 |
| 技术装置 | Pip-Boy／隐身小子主题 | 有限能力或专业效果 |
| 白金筹码 | 独立任务的专属非武器装备，优先护符／附魔物品类槽位 | 任务／技术支援效果，保留单武器约束 |
| ED-E | 修复／接触任务后取得邮差专属随从 | 侦察与射击辅助，原版附属物槽位与叠加限制待核 |
| Rex | 寻访／修复任务后取得邮差专属随从 | 侦察与追踪，原版附属物槽位与叠加限制待核 |

ED-E与Rex按随从奖励记录唯一取得状态；具体可同时装备数量、转移权限与效果沿原版槽位核对。六位人形伙伴采用实际人物实体，其作用由人物技能、嵌入效果及合法装备提供。

### 7.2 六位人形伙伴

邮差加入后解锁队友任务链，参考高崔克／菲利克斯组合获取的跨派系人物体验。六人各为全战役唯一传奇事务官方向，通过个人任务逐步加入；可与邮差同军，也可分军嵌入或执行英雄行动，均使用正常英雄席位与维护，不统军。任务内容与战斗专业为助手初设，具体叙事由世界维护，人名／专业人物条目由种族维护。

| 队友 | 任务初设 | 个人作战与嵌入职责初设 | 阵营条件 |
| --- | --- | --- | --- |
| 维罗妮卡 | 寻找旧技术并完成一次修复／救援委托 | 近战与装备支援，动力拳套动作宿主待核 | 拒绝与钢铁兄弟会敌对；加入后所属玩家进入相应战争则永久离开 |
| 布恩（Craig Boone） | 完成一次侦察与保护目标的战斗委托 | 远程点杀、观察与适用射击支援，持枪英雄宿主待核 | 拒绝与NCR敌对；加入后所属玩家进入相应战争则永久离开 |
| Cass | 处理一次商路／车队纠纷 | 中近程射击、行动与维持支援，武器动作待选 | 额外阵营离队条件待定 |
| 阿凯德 | 医疗救援及技术回收委托 | 有限医疗与技术支援，合法目标引用A02／A03 | 额外阵营离队条件待定 |
| 劳尔 | 修复设施／设备并护送脱险 | 侧重维修与持续作战支援，个人射击宿主待选 | 额外阵营离队条件待定 |
| 莉莉 | 完成保护友方人物或聚落的委托 | 隐蔽接近与近战，体型、动作及心理属性待核 | 额外阵营离队条件待定 |

每项任务完成后核对人物唯一身份、既有归属与领取状态，再加入该实体；已存在时沿用对应人物与任务状态，不生成同名随从或第二英雄。任务以实际角色职责组织，不改变邮差的一武器、至多两Trait与三次Perk选择预算。维罗妮卡实际参战触发马德雷克里斯汀事件的规则继续生效，具体见2.2及共通6.9。

### 7.3 战争与永久离队

外交资格按实际战争判断，好感低不等于战争。助手初设按种族归属识别钢铁兄弟会及NCR各派系；与其中任一实际开战即满足对应伙伴条件，身份映射由种族提供。宣战、被宣战、同盟或附庸关系引入的战争均按最终实际战争状态检查。

加入前已经处于相应战争时，暂停该伙伴的加入任务，和平后可继续，这是助手初设。加入时与外交变化时明确提示对应伙伴的永久离队条件。加入后触发战争，记录该玩家派系对该人物的永久离队状态，之后和平、解散重招、重复任务回调及加载已记录离队的存档均不恢复领取资格。永久离队与死亡、普通受伤返回分别保存；受伤中的伙伴满足条件后也不得按伤愈流程重新加入。其他四人不额外套用这两项政治条件。

若在战斗或事件结算期间触发离队，初设先记录不可再领取状态，待安全结算点撤出实体；具体回调与人物退场顺序待技术核对。离队只处理该英雄、个人任务及合法装备，不删除所在军队其他部队、不改变邮差构筑。装备处理初设为通用可转移物品回所属派系物品池，个人绑定专装随人物离开；库存权限、技能／嵌入效果撤销、进行中任务取消与物品去重均待宿主核对。

军团／掠夺者普通领主叛变时，伙伴按实际实体与归属转移，不随领主装备记录复制；新归属若触发其战争离队条件则进入永久离队结算，NCR撤职保军不等于整军叛变。好好先生开局来源、普通任务来源与合邦所得均共用唯一领取及离队记录。

离队后的角色去向与其他派系获取权限保持待定；原玩家派系的禁止重新获取状态随战役存档保存。

## 八、生命周期与持久状态

| 情形 | 功能处理方案 |
| --- | --- |
| 尚未招募 | 全局唯一实例不存在；任务状态可持续，不重复创建 |
| 创建完成 | 保存唯一身份、玩家归属、武器路线、已领装备与选择记录 |
| 受伤 | 按传奇英雄返回原型处理，返回后保留已选路线和名额 |
| 真正永久失去 | 不重新赠送一套全新构筑；是否能重现按目标宿主支持情况决定，不能用新人物重复领奖 |
| 解散／重招 | 不重开招募奖励、Trait与Perk事件；复制奖励必须被阻止 |
| 玩家合邦取得人物 | 保留人物已有选择与物品；不根据新派系重发任务 |
| 归属派系灭亡 | 先采用宿主合法返回／移除行为；跨派系重新出现若无法保留完整状态，则列技术阻塞，不静默刷新角色 |
| 普通技能重置 | 只重置可重置技能；永久构筑选择不变，旧效果不能残留叠加 |
| 保存载入 | 记录与实际人物核对，不把任务回调重入当第二次选择机会 |

首版不开放武器路线重选和Trait／Perk重配，避免为方便而开发整套状态迁移。未来若扩展必须先有可靠撤销效果与物品的技术路线。

## 九、实施级设计的未决输入

“生成前定武器＋事件有限选择”为当前主路线。菲利克斯／高崔克英雄子类型及技能选择关系已有[定位证据](../技术设计/技术概要设计.md#107-邮差传奇事务官与有限选择)，普通事件选择有局部存档证据；四武器变体的共享唯一性、动作适配、物品槽位及返回行为仍未证明。每种子类型cap=1不等于全战役共同唯一。

种族需确认获取资格与队友归属，世界需落实可达任务地点及终点和平判定；大兵路线待收敛实际弹丸、技能点预算及装备效果。六位伙伴的唯一实例、同军／分军、战争暂停与永久离队标记、装备和任务安全退场需技术集中登记；邮差生命周期、选择去重与继承的待验证问题统一见[DV-030](../可行性验证/首批可行性验证方案.md#十当前设计组合待验证清单)。

## 十、大兵路线与共通装备边界

本节是第三节大兵路线的代表初设，预算与身份约束见第一节；其余三路线仍保留方向，四套动作尚未全部就绪。

### 10.1 具体宿主与武器行为

大兵路线优先采用帝国工程师英雄的连发步枪动作宿主；[技术概要10.2](../技术设计/技术概要设计.md)已有该英雄单位、动作与人形骨架定位。保持步行射击英雄身份和宿主装填、射界、射击节奏，军用自动步枪是该动作链的表现主题。弹丸、基础／破甲比例、移动射击权限及具体弹药仍待实际目标数据核对，不增加第二种射击模式。

采用工程师个人射击骨架，能力按邮差路线另行选择。特殊射击若另行选用，必须交代弹丸与伤害属性；普通步枪不因科幻主题获得魔法攻击。基础→强化武器升级保持同一射击行为，只采用目标宿主支持的同路线提升，不变成狙击或霰弹切换。

装备物品未必能直接替换战斗武器与动作。生成前定路线负责选择合法战斗变体，专属武器物品负责绑定该路线的奖励与效果；真实装备槽位、物品权限、升级撤销旧效果仍是技术依赖。

### 10.2 一条路线内形成不同Build

以下是现有选择池的衔接例，不新增名额或额外赠送能力；选项都是初设，效果数值优先沿实际可用宿主。

| 方向 | SPECIAL投入重点 | 两次Trait取舍示例 | 三阶段Perk示例 | 代价与装备约束 |
| --- | --- | --- | --- | --- |
| 阵地射手 | P射击／A装填，E只作有限生存投入 | 沉着射手＋重装倾向 | 突击队员→坚韧→血肉横飞 | 慢射与低机动代价保留；防具不再额外送屏障、常驻潜行和近战专精 |
| 机动射手 | A机动／装填，P补射击 | 快枪手＋小个子 | 快速装填→轻装快步→死神冲刺 | 命中效率与生存代价保留；机动不自动意味着移动射击合法，冲刺不恢复弹药或刷新全部技能 |

I医疗／装置与C支援仍消耗普通技能投入，不自动发给每个Build。七主题不等于七条完整能力线全满；真实技能点预算未核前，不填写可同时点满的节点数。Trait不能出现宿主无对应负效果的“免费正面选项”，否则该选项保持待配，不能删除代价后先发奖励。

第一阶段大兵候选“坚韧”与第二阶段同主题重复时，后者按第六节换成有效候选；重复领取不能叠成额外Perk。神秘陌生人仍只是一项第三阶段终点选择，不与上述血肉横飞或死神冲刺同时领取。

### 10.3 防具、治疗、隐蔽与随从

游骑兵装甲／信使风衣按人物装备宿主配置。先选本人装甲或机动的一项主用途，重装Trait的移动代价不能被同件免费护具全部抹平；无具体物品宿主前保留数值待定。首批步行，不增加坐骑路线或借飞行装备越过战役封闭边界。

治疗与隐身引用[共通战斗规则](./战斗/通用战斗与能力设计.md#六共通战斗与能力规则)。邮差个人治疗若采用，需指定支持本人、有限次数且不复活的宿主及获取条件。隐身小子来自有限装置或专精获取，不能让大兵通过共享物品补齐狙击路线的潜行组合。

白金筹码仍是非武器专属装备；不得附送另一武器路线、免费全部治疗／护盾／召唤或额外Trait／Perk名额。阿凯德与劳尔的医疗／维修来自各自英雄技能及合法目标；邮差不会因解锁伙伴再取得同名附属物能力。ED-E／Rex的附属物效果、转移权限与槽位仍待核。
