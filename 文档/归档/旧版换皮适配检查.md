# 原版设计换皮适配检查

> 历史归档：不作为现行设计依据。当前内容见[归档说明](./归档说明.md)与[项目概念设计](../../项目概念设计.md)。下文保留归档时的措辞和状态。

目的：从战锤3已有内容检查尚未审视的适配问题。战锤是玩法根本，辐射提供身份与表现，不从题材反向生成新系统。

## 一、处理方式

每项只判断：原样沿用规则／更换名称和表现／少量数据适配／不采用／待查原型。没有合适对应，不默认新造替代系统。

本表按设计问题分类，不是数据库枚举。某项只存在于部分原版文化，不意味着每个派系都要采用。当前是审阅目录，不代表已核验具体版本实现。

## 二、已被用户指出、需要继续核对的方面

| 原版方面 | 已有讨论方向 | 尚需审视的规则与表现 |
| --- | --- | --- |
| 兵种与成长 | 按原版兵种表组织辐射兵表 | 低级兵用途、专业分工、变体与人数原型 |
| 城市与攻城 | 弱化城墙，参考现成工事与场景 | 城门、塔、器械、占点、破坏与寻路 |
| 法术与能力 | 按效果类型更换为药物、装备和支援 | 施法动作、资源、过载失误、范围与死亡表现 |
| 飞行 | 稀缺单位、临时召唤或场外能力 | 落地、对空对地、召唤退场和 AI |
| 腐蚀与损耗 | 辐射作为适配候选 | 原有作用范围、结算、视觉与免疫，避免附加生态模拟 |
| 驯兽与特殊招募 | 驯兽领主与生物部队候选 | 原版招募权限和强化范围，不默认新造捕获系统 |

## 三、尚未充分审视的原版方面

| 编号 | 原版设计 | 换皮时容易遗漏的问题 | 默认处理方向 |
| --- | --- | --- | --- |
| A01 | 士气、恐惧、惊骇、狂暴与不溃 | 外观换了但心理表现是否合理；机器和生物是否被随意套上同一种状态 | 保留原版体系，按选定单位调整标签，不建新心理系统 |
| A02 | 亡灵崩溃、恶魔消散与指挥依赖 | 移除领主后掉血、消散或整军瓦解未必适合新的单位身份 | 使用这种原型前明确是否接受；不合适则更换原型或不采用 |
| A03 | 治疗、再生、复活与召唤 | 活着的模型回血、死者重新出现、新单位生成是不同表现；消散也有残留特效 | 分别选现成效果，不能只改技能名 |
| A04 | 护盾、物理／法术等抗性与接触效果 | 破甲、魔法、火焰、毒素、魔屏的实际作用与新名称是否一致 | 保留实际规则，少量属性调整，不另建弹药克制系统 |
| A05 | 人物坐骑、战车与大型形态 | 骑乘、换形、悬浮、起飞、落地、死亡等动作不是普通模型外观 | 优先保留兼容骨架动作；不为每个人物补专属载具 |
| A06 | 近战攻击动画、质量、击飞与溅射 | 新形象是否仍能完成原型的横扫、撞击、吞咬、特殊处决等动作 | 选择表现相容的原型，不用数值掩盖动作矛盾 |
| A07 | 特殊射击方式 | 吐息、喷射、齐射、追踪、弹跳、穿透等不能仅按枪名归类 | 原样参考弹道和武器行为，再选择外观 |
| A08 | 隐形、潜行、先锋与特殊移动 | 隐蔽、钻地式通道或跨障碍移动可能带有强烈奇幻表现 | 保留可接受部分，其余不采用；不新增渗透玩法 |
| A09 | 装备、旗帜、随从、特性与传奇任务奖励 | 单位换皮不覆盖人物装备槽位、图标、特效和文本；部分能力仍露出原身份 | 沿用成长与槽位结构，选择必要内容替换 |
| A10 | 驻军、叛军、召唤和援军名单 | 主兵表改了，自动生成军队仍可能出现原版单位 | 检查引用来源，按现有结构替换，不增加新招募机制 |
| A11 | 气候、地形损耗与腐蚀 | 三者并非同一规则；界面与地图上可能保留不合适名称和视觉 | 分别保留或适配，不为每个原版类型新造一种污染 |
| A12 | 地下据点、游牧建筑与特殊占领 | 某些原版文化不按普通聚落方式经营 | 使用该文化原型时先审视整套依赖，不按题材主动引入 |
| A13 | 文化专属资源、仪式与全局机制 | 选择文化原型可能带入额外界面、资源或脚本 | 先审视原型包袱；优先选择需要改动较少的基础 |
| A14 | 海域、海上移动与相关事件 | 原版海上内容可能在新地图失去意义 | 无需要就不采用，不为保留而增加海军 |
| A15 | 任务战、危机、叛乱与胜利 | 原脚本、生成军队、地点和任务条件可能继续引用原版世界 | 保留需要的框架，替换或不启用不适用内容 |
| A16 | 自动结算、AI 与模式限制 | 手动战斗换皮成功不能说明自动结算、AI 和自定义战斗都适用 | 作为既有实现的检查项，不因此扩大玩法 |
| A17 | 界面、音频、特效与地图表现 | 魔法动作、吟唱、旗帜、结算画面和环境视觉可能残留 | 列替换清单，区分必要修改和可接受的原版表现 |

## 四、优先顺序

先审视会决定原型选择的 A01—A08，尤其亡灵／恶魔状态、恢复与召唤、坐骑和攻击动作。然后检查人物成长和文化原型附带规则；最后在具体制作范围内检查自动生成内容与表现残留。

不是把 A01—A17 全部设计一遍，而是对照现有方案找出真正的适配冲突。不存在冲突的通用规则直接沿用。

## 五、下一步记录格式

原版对象 → 保留的玩法 → 不能直接接受的规则或表现 → 最小改动／不采用 → 技术未知项。

不使用“辐射有某内容，因此必须增加某系统”的推导。现有原版参考库继续补录具体实例，本文作为适配问题检查入口。
