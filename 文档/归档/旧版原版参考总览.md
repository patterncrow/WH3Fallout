# 战锤3原版设计参考总览

> 历史归档：不作为现行设计依据。当前内容见[归档说明](./归档说明.md)与[项目概念设计](../../项目概念设计.md)。下文保留归档时的措辞和状态。

版本：参考初稿 0.1。用途：与本项目设计并行存在的原版设计检查库。

## 一、使用原则

查漏优先使用[原版设计换皮适配检查](../原版参考/战锤设计对比参考表.md)，检查战锤既有设计的规则与表现，不从辐射题材反向扩展新系统。

先整理战锤提供的设计，再为辐射选择对应，不以辐射已有角色和装备数量反向裁剪原版参考。参考项不等于项目必须采用项，也不等于技术上可任意移植。

本库本轮整理的是设计分类、规则维度、内容结构、典型例子与逐项检查表。未将其标记为全部文化、单位、技能、科技、装备的逐条数据全集。具体名称、数值、解锁等级、效果键及现行版本差异，需要目标游戏版本确定后逐项补录；不能凭旧攻略填写。

表中的功能分类供设计比较，可能交叉，不冒充游戏界面的严格互斥分类或数据库枚举。每一派系应逐项写明：采用／改编／不采用／待定，记录原因。

## 四、原版实例补录规范

实例状态区分：概念例子／公开资料已查／本地原版已核／项目试验已过。当前未完成本地原版盘点，不填未经核对的精确值。

后续按原版文化逐一补充代表兵表、普通领主／英雄类别、技能树、科技树及专属机制。这个补录与辐射文化设计并行进行，不用一张抽象检查表替代具体原型核对。

## 六、后续顺序调整

先补齐原版参考，再以覆盖表审阅本项目通用规则与文化卡，然后设计具体派系。当前文化卡中的兵种倾向是待对照的建议，不作为已经锁定的兵表。

城市战的弱化城墙、工事破坏和进攻工具等想法，先登记为候选，通过原版场景与技术路线对照后再进入功能承诺。

## 七、核心体系复查：补足文化专属玩法目录

先前适配检查包含较多单位级规则。此表回到会改变战役循环、经营方式、兵力获取、成长或政治关系的体系。列入参考不代表全部纳入项目，也不代表能够跨文化直接移植。

| 核心体系 | 已知原版参考方向 | 本项目当前状态与需要补录内容 |
| --- | --- | --- |
| 普通贸易与实体商队 | 震旦商队、混沌矮人商队等 | 商路可作为派系绑定候选；区别贸易收入与路线、护卫、遭遇、目的地奖励，补录具体原型 |
| 外交协作与盟军军事 | 前哨、盟军招募、战争协调及适用借军规则 | 已在分类中提及，但需要独立整理整体流程与权限，不只写条约清单 |
| 特殊招募与兵源池 | 精英部队、战后兵源、怪兽池、地区池等 | 比较来源、库存、恢复、冷却和限制；不同原型不能自动混合 |
| 已有部队升阶 | 战团升级等单位转化路径 | 与重新招募和经验加成分开，补录成本、经验、分支及保留状态 |
| 人物晋升与专属成长 | 荣耀之路、誓言、头衔及特定文化成长 | 与普通加点分开；用户认为变形较难解释，不将外观变形列为必需 |
| 非普通聚落经营 | 军队建筑、营地、黑色方舟等参考 | 分别登记移动基地、固定营地等实际行为，不能当成通用可移动城市 |
| 他方领土内据点网络 | 地下帝国、海盗据点、教团等 | 与占领城镇和地区腐蚀区分；补录发现、扩展、收益和摧毁规则 |
| 仪式与付费战略行动 | 各文化仪式、献祭、赐福或类似机制 | 与普通战斗技能分开，补录资源、冷却、事件与军队效果 |
| 内部政治与统一 | 席位竞争、官职、权威、忠诚、合邦条件等 | 不是一套通用政治系统；各原型分别观察，按派系需要选择 |
| 特殊经济与军力约束 | 多资源转换、劳动力、容量、特殊维护等 | 普通金钱经营之外的文化差异；不是为每文化配齐所有资源 |
| 对外战略操纵 | 适用文化的阴谋、改变局势或外交干预机制 | 与常规外交和事务官行动分开；仅收录可定位的具体实例 |
| 探索、收集与特殊地点 | 遗迹遭遇、物品收集目标、特殊地标及任务战等 | 区分固定／随机、场景战斗／事件结果和长期据点；不默认存在通用 RPG 地下城系统 |
| 扩张型战争机制 | 额外战争动员、征讨目标与战果驱动成长等 | 与普通宣战、战后金钱和胜利条件分开，补录具体文化原型 |
| 世界状态与后期变化 | 危机、裂隙等战役限定内容 | 区分沙盘与特定战役适用范围，不默认可直接复制到新地图 |

普通建筑科技、人物加点、兵表、战斗、腐蚀、任务和胜利等基础体系沿用前述目录。此次主要补足“专属机制”过于笼统的问题，不额外创造辐射体系。

### 用户已说明的表现接受范围

- 恐惧、惊骇、狂暴与不溃等可保留；特殊消散／崩溃可用于合适的特殊单位。
- 治疗、再生、复活、召唤等可以寻找对应身份；仍按具体原版规则选用。
- 坐骑与单位形态允许较大架空，包括马、双头牛、载具、死亡爪乃至飞行死亡爪；这些是表现许可，不是技术实现结论。
- 优先按现成单位换皮，例如恐虐大魔类原型与死亡爪、抬枪类原型与反器材射手的候选对应；是否适配具体动作另核。
- 潜行与特殊移动可以保留；派系确有需要时允许科幻解释，不因此预设每派系都需要特殊移动。
- 不涉及海军；变形较难解释，先不列为普遍采用内容。
- 商路、特殊地点与随机事件等可用辐射身份表达，先定位原版结构，再决定具体内容。

### 术语与来源边界

“地下城”需拆清：地下帝国式隐蔽据点属于领土网络；进入地点触发选择或战斗属于遭遇／任务结构；多层探索副本不能仅凭名称当成已有通用体系。

“特殊随机建筑”也需区分固定地标、随机出现的地点、随机事件奖励与随机建筑位置；先查原型，不直接承诺地图运行时任意生成建筑。

[SEGA 混沌矮人机制介绍](https://sega.prezly.com/total-war-warhammer-iii-the-forge-of-the-chaos-dwarfs-is-out-now)提供商队与席位竞争的明确原版实例；[混沌冠军官方公告](https://steamcommunity.com/ogg/1142710/announcements/detail/3394042289192800697)可用于战团、赐福、黑暗要塞和荣耀之路等机制补录。具体当前数值与移植条件仍需目标版本核对。
