## 一、人物身份与使用方式

| 身份 | 基础作用 | 需区别的内容 |
| --- | --- | --- |
| 传奇领主 | 独特人物，常作为开局派系领袖 | 派系特性、领主特性、专属技能、装备及获取方式分别登记 |
| 普通领主 | 从对应池招募，统领军队 | 类型、初始特性、技能与兵表倾向 |
| 普通事务官／英雄 | 独立战役行动或加入军队参战 | 容量、招募、行动权限、嵌入效果和战斗定位 |
| 传奇英雄 | 独特支援或战斗人物 | 获取、唯一性、专属技能与死亡返回规则 |
| 特殊人物或转化类型 | 某文化机制提供的人物形式 | 例外单独核对，不视为所有文化通用 |

人物是否可玩、是否派系领袖、是否传奇、是否能统军是不同维度。派系拥有多个领主，不等于拥有多个独立经济或外交实体。

## 二、领主类型参考

以下是功能分类；同一个实际领主类型可占多个位置。

| 类型 | 战斗职责 | 技能重点 | 原版定位例子 |
| --- | --- | --- | --- |
| 近战统帅 | 承伤、决斗或突破 | 个人战斗与军队加成 | 帝国将军、矮人领主类 |
| 远程猎杀型 | 射击重要目标 | 射击、机动与指定部队 | 猎人将军类 |
| 施法领主 | 通过法术改变局面 | 法术、资源与军队成长 | 高等法师等 |
| 近战施法混合 | 同时承担接敌与法术 | 两类能力的取舍 | 吸血鬼领主等 |
| 宗教／光环支援 | 强化周围部队 | 增益、战斗祈祷或支援 | 大诵经师类 |
| 怪兽或大型领主 | 高质量单体战斗 | 原生大型形态与能力 | 部分恶魔领主等 |
| 专业军队统帅 | 自身战斗为辅，偏向某类配军 | 特定单位或战役倾向 | 各文化专门类型与传奇人物 |

不要求每文化都拥有全部类型。步战、坐骑与大型形态也不是完全独立的人物职业。

## 三、事务官类型参考

| 类型 | 战场定位 | 战役／嵌入参考方向 |
| --- | --- | --- |
| 近战战士／护卫 | 决斗、护卫领主、近战输出 | 训练、秩序或行动，依具体类型 |
| 施法者 | 伤害、控制、恢复或增益 | 魔法相关、地区影响等 |
| 工程／远程专家 | 射击、机械或炮兵支援 | 军队火力与补给相关效果等 |
| 祭司／支援者 | 光环、祈祷和强化 | 秩序、净化、补员等 |
| 刺客／潜行者 | 机动、潜行和猎杀 | 刺杀、伤害或阻碍等 |
| 混合型／特殊英雄 | 多种职责组合 | 按该类型实际权限登记 |

这些不是可自由赋予任何英雄的固定行动包。专业名称不能自动证明拥有某项行动。

## 四、领主技能树的设计层

| 分支或节点 | 常见作用 | 需要检查 |
| --- | --- | --- |
| 战役线，常称蓝线 | 移动、补员、招募、维护、损耗、战后收益等 | 每项作用范围与实际类型，不假定一套蓝线适用所有人 |
| 军队线，常称红线 | 强化指定兵种组或军队能力 | 单位集合是否覆盖新兵表，经验条件与分支选择 |
| 个人战斗线，常称黄线 | 攻防、生命、伤害、射击等 | 与人物动作及定位匹配 |
| 法术线 | 解锁法术、强化施法与资源利用 | 法术派系、升级、过载及附带效果 |
| 独特线 | 人物身份、指定部队或特殊能力 | 是否与派系特性重复，是否改变玩法 |
| 坐骑与形态 | 战场机动、攻击与生存改变 | 实际获取方式、模型、动作与切换限制 |
| 关键独立节点 | 不朽、能力或专门被动等 | 等级、前置、类型和版本差异 |

颜色是便于交流的常见称呼，不是所有人物技能树都严格具有同样颜色和分支。

## 五、事务官技能树的设计层

| 分支 | 作用 | 应与什么对应 |
| --- | --- | --- |
| 战斗成长 | 近战、射击、装甲、生存等 | 实际人物原型 |
| 法术成长 | 法术与施法支援 | 施法类型与法术派系 |
| 战役行动强化 | 成功率、成本及相关效果 | 该英雄实际拥有的行动 |
| 嵌入军队强化 | 训练、补员或其他支援 | 明确的军队范围与叠加规则 |
| 地区被动强化 | 收入、秩序、腐蚀或净化等 | 所在区域的实际作用范围 |
| 专属与解锁 | 坐骑、独特能力或传奇效果 | 前置、独有性和生命周期 |

不默认事务官具有完整的领主红线，也不因加入军队就自动获得统军权限。

## 六、技能节点规则

| 检查项 | 记录内容 |
| --- | --- |
| 入口条件 | 人物类型、等级、前置节点与前置投入 |
| 投点 | 节点等级数、每级效果、点数来源及是否自动解锁 |
| 分支结构 | 串联、并列、门槛、互斥和终点节点 |
| 作用对象 | 仅本人、所率军队、嵌入军队、地区、派系或指定单位组 |
| 效果形式 | 数值、被动、主动、招募权限、法术或坐骑 |
| 持续与叠加 | 永久、条件生效、同类是否叠加、失效条件 |
| 配军关系 | 是否漏掉新单位，是否误加成共享原型或敌方单位 |
| AI | 自动加点的选择与必要节点可达性 |
| 重置 | 目标版本是否支持、成本与状态处理，不能默认无限免费重置 |

## 七、特性、装备与技能分开

- 派系特性：派系级身份及效果。
- 领主／人物初始特性：选定人物或招募候选的差异；游戏内表现与底层实现另行核对。
- 后天特性：战斗、行动、地区经历或其他条件获得的变化。
- 击败特定领主奖励等：获得条件、作用与版本需单独记录。
- 技能：等级与投入形成的成长结构。
- 装备与随从：可装备或分配对象，存在槽位与适用限制。

装备参考检查：武器、防具、护符、附魔物品、奥术物品、旗帜及随从等实际类别；稀有度、获取、专属条件、主动能力、重复、合成或处理方式。并非每个人物都能使用所有槽位。

坐骑不只改变外观，可能改变体型、速度、动作、目标受击面积及技能表现。用坐骑表达载具需要单独确认，不能按名称直接替换。

## 八、事务官行动与被动参考

候选行动维度：侦察与视野、伤害或刺杀人物、阻碍军队、袭击部队、破坏建筑、防御相关行动、技术相关行动、地方秩序及腐蚀相关影响。

每个实际类型分别填：主动行动／地区被动／嵌入效果／不具备；并记录目标、成本、成功与暴露、失败、冷却、经验和 AI。

不能把“破坏防御”泛化为炸毁任意场景建筑或强制野战；战役效果和战斗地图变化是不同能力。

## 九、人物完整生命周期

获取或招募 → 初始状态 → 带军／嵌入／独立行动 → 经验与加点 → 装备坐骑 → 受伤或死亡 → 返回或永久失去。

需覆盖：容量、候选池与刷新、任务解锁、唯一性、替换与解散、重招、忠诚或其他文化例外、合邦后归属、派系灭亡与返回位置、保存载入。

## 十、派系人物设计交付表

邮差的 SPECIAL、有限 Trait／Perk、互斥武器流派、专属装备与队友随从已另列[人物初设](../功能设计/邮差传奇事务官设计.md)。这是传奇事务官的内容组织，不改变本参考中的英雄统军边界，也不要求其他英雄全部采用 SPECIAL。

每个文化分别登记普通领主类型、普通事务官类型、传奇领主与传奇英雄；每类型关联技能树、行动包、招募条件、坐骑、装备范围和原型。

每个传奇人物同时检查：派系特性、个人特性、技能、任务、装备五个位置是否重复堆叠同一加成。
