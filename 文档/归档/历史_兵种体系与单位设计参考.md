## 一、阅读方式

先按战锤兵种体系列出候选位置，再在派系设计中选择需要的部分，并填入辐射身份和原版原型。表中的例子仅便于定位，不构成完整兵表或强弱结论。

兵种形态、武器、职责、伤害属性、招募等级彼此独立。例如远程单位可以是步兵、骑兵、怪兽或单体；反大型不是一种体型；高等级也不必覆盖所有低等级用途。

## 三、战术职责：与上表交叉使用

| 职责 | 需要的主要条件 | 常见代价或反制 |
| --- | --- | --- |
| 承线 | 防御、士气、人数、装甲或抗性 | 输出与机动可能较低 |
| 杀伤普通步兵 | 合适攻击动作、反步兵或范围输出 | 被远程及反制单位针对 |
| 反大型 | 反大型、射击或足够单体伤害 | 不自动等于通用强兵 |
| 破甲 | 足够破甲比例和有效命中 | 成本、射界或攻速限制 |
| 突破 | 冲锋、质量、动作和集中输出 | 持久战、狭窄空间或反冲锋 |
| 机动袭扰 | 速度、部署或移动射击 | 血量、弹药与操作负担 |
| 远程压制 | 射程、持续输出与可用射界 | 被迫移动、遮挡与近战切入 |
| 狙击重要目标 | 精度、伤害与视线 | 对密集普通兵的效率有限 |
| 追击 | 速度和适合的攻击方式 | 正面价值可能有限 |
| 支援 | 增益、恢复、控制或光环 | 依赖其他部队、技能资源或冷却 |
| 工事破坏 | 原型允许攻击对应目标且有效 | 有爆炸特效不等于能摧毁场景 |

## 四、单位属性与表现核对

| 维度 | 应整理的项目 |
| --- | --- |
| 编制 | 模型数、单位规模设置、单模型生命、总生命、占军队位置方式 |
| 身体与机动 | 体型类别、速度、质量、加减速和转向相关表现、地形通过、飞行与落地 |
| 近战 | 近战攻击、防御、基础与破甲伤害、攻击间隔、范围动作、反步兵／大型、冲锋 |
| 远程 | 射程、弹药、装填、精度／散布、弹速、射角、移动射击、投射物与爆炸 |
| 防护 | 装甲、盾牌格挡及方向、物理／远程／法术／火焰抗性、特保、魔屏 |
| 心理 | 领导力、恐惧、惊骇、免疫心理、不溃、狂暴，以及特定单位的崩溃或消散规则 |
| 状态 | 疲劳、隐蔽、潜行、先锋部署、再生、治疗上限及原型其他特性 |
| 主动能力 | 次数、资源、冷却、持续时间、目标条件和 AI 使用 |
| 实际表现 | 骨架、动作、攻击接触、武器位置、射击点、碰撞、击退与死亡 |
| 经营 | 招募费、维护、招募时间、前置建筑、等级、容量与补员 |

表内部分项目是行为或数据维度，不一定全部显示在兵牌上。改属性不能自动获得对应动作与碰撞表现。

## 五、伤害与防护必须分开建模

基础伤害／破甲伤害决定装甲处理；物理或魔法攻击影响相应抗性处理；火焰属性与法术来源另有规则。它们不是互斥的一列伤害类型。

魔法攻击不自动绕过装甲，法术抗性也不等同于抵抗所有带魔法属性的武器。魔屏是另一种保护机制，不能只按名称解释成防激光装甲。具体公式和数值以后按目标版本核对。[官方伤害说明](https://community.creative-assembly.com/total-war/total-war-warhammer/blogs/6-feature-focus-2-damage-part-1)

## 六、兵表层级与特殊获取

| 项目 | 原版参考作用 | 应检查 |
| --- | --- | --- |
| 基础兵 | 建立常规军队 | 低成本、补充与后期用途 |
| 专业兵 | 承担特定职责 | 有适用场景，也有短板 |
| 精锐兵 | 提升局部能力 | 是否需要成本、数量或条件限制 |
| 武器变体 | 同一组织不同职责 | 是否有足够战术差异，不能仅改名 |
| 精英／特殊军团 | 特殊获得与有限供给 | 获取、容量、冷却、补员与 AI |
| 雇佣／盟军部队 | 补足或交换能力 | 来源、驻地、关系、招募与维护条件 |
| 临时召唤 | 战斗中获得短期兵力 | 是否衰减、时限、次数、能否带出战斗 |
| 升阶／转换 | 已有单位成长或换类 | 哪些文化支持、所需经验和资源，不能默认普遍可用 |

建筑层级、科技、单位经验、人物军队加成是不同成长路径，不能把它们都称为兵种升级。
