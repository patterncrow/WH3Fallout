# 战锤种族与派系特色机制目录

版本：目录初设1.0，2026-11-03。用于先横向比较原版机制，再由种族负责人组合辐射内容；不是采用清单或移植通过表。主体以传统24种族为起点，补入官方9.0纳加什亡灵军团，共25个种族／独立内容入口，包含WH1／WH2移植和WH3新增分支。独立索引采用TW-种族缩写-序号，不替代现有SYS、C、F、U编号。

## 证据与版本口径

本机既有记录为9.0.4.0／Steam build 25961564，仅引用[资源记录](../项目管理/资源与环境准备.md)，实际组合未据此核验。官方网页于2026-11-03查阅；官网旧版介绍证明原型出处，不证明9.0.4参数、面板、AI或跨文化移植可用。

- **官**：已读到CA／Total War发布正文或开发者Steam商品说明，支持该行主要功能；仍待本地当版核对。
- **旧**：官方WH1／WH2或早期WH3介绍，仅支持历史原型；当版改动未逐项核实。
- **待**：目录保留的原型线索，尚未逐项取得直接官方功能正文；名称、范围及当前行为待核，不能作为已定位数据。
- **项目**：只有技术概要所引报告列明的对象才有本地数据或局部游戏证据；本目录不把“官／旧”升级为“项目通过”。

各行适配方向均为助手候选；已有用户决定仍以功能正文为准。“共享／差异”记录领主特色与共享体系的差别，独立经营面板另列。普通战斗技能、每个科技数值和单件任务装备不逐项扩为特色机制。

官方9.0的Undead Legions／亡灵军团作为第25项单列纳加什，不与第三方Legions of Nagash模组混同，也不塞回吸血鬼或古墓王。该原版目录扩充不等于本Mod新增可玩种族。官方[9.0.4公告索引](https://community.creative-assembly.com/total-war/total-war-warhammer/forums/7-patch-notes-amp-announcements)又记录纳加什招募、建筑与合邦修复，故9.0发布介绍不能替代9.0.4运行证据。

## 组合检查与责任接口

当前适配按[设计总纲](../功能设计/设计总纲.md)消费：异形为共享种族、尸鬼为分支，掠夺者仅大汉帮可玩，大山脉仅F21。聚落中义勇军以纳卡伊代理、特殊驻地、盖特曼治理作三个独立待验组件；合成人暂全AI，学院付费赛尔式行动与铁路安全屋分别比较TW-NOR-05、TW-TZE-02，不整套复制，阿卡迪亚不取得学院制造能力。详细组合不在原版目录重复维护。

先问一种组件负责什么：资格、库存、支付、单队强化、全类研究、周期或地区状态。相似收益不重复收费；并非每族都要晋升、废料、工坊和挑战四套齐全。具体采用由种族正文维护，目录只供比较。

| 边界 | 合并前需要的答案 |
| --- | --- |
| 资源与UI | 是否硬绑定文化、派系或面板；两个资源能否并存；账本是军队、城镇、行省还是派系；原型免维护／免费兵不随便继承 |
| 库存与容量 | 池是全局还是本省；产出与普通建筑、任务奖励能否分源；转兵、合邦、失地是否绕容量；池内经验和效果能否持久化 |
| 状态与继承 | 哪些是单队改造，哪些是单位类别效果；转换、解散、受伤、重招、易主、周期重置和读档的继承、扣除与去重 |
| AI | 原版AI是否会使用独特按钮与任务；基本建筑招募先成立，不能用AI免费全解锁替代缺失行为 |
| 地区与灾害 | 建筑周期不等于省周期；效果包不等于真实天气。损耗免疫、建筑损坏、防护范围和战斗强化分别核对 |
| 成本与节奏 | 采用主要稀缺约束加必要成本，避免五重门槛；基础兵长期有用，多军队总经济须算额外军队负担 |

异形已确认肉食取TW-SKV-01派系账本，周期先核TW-NUR-01；斯洛特培养缸／血肉实验室TW-SKV-05、瘟疫巨釜TW-NUR-02属于重点考察对象，尚未选为四阶段必加系统。技术映射见[概要8.5](../技术设计/技术概要设计.md#85-成长转换与自动结算的最低约束)，待验证问题与最低门槛唯一见[验证方案第十节DV清单](../可行性验证/首批可行性验证方案.md#十当前设计组合待验证清单)。
