# 新维加斯装备生物与单位设计参考

供Mod选取装备、单位外观、生物和机械形态时查阅。同类型号、强化版、损坏版与人物换装合并，只保留有辨识度的内容。下列用途是设计素材候选，当前采用由[设计总纲](../功能设计/设计总纲.md)及其责任正文决定；采用时仍先找战锤3的具体原型。非音频原始资产仅作外观与设定参考。

当前Mod归类为异形（含尸鬼、变种人与相关生物）、掠夺者、大山脉等；以下仍保留原作生物与装备标签。F21共享大山脉实验体／毒气，F22及伊芙已撤销；学院、铁路、阿卡迪亚按合成人暂全AI方向消费素材，不由此表增加可玩派系。普通聚落、义勇军与大炮族的权限各见种族正文。

## 生物与特殊人形

| 家族 | 保留形态 | 设计参考意义 |
| --- | --- | --- |
| 昆虫与蝎类 | 辐蝎、吠蝎、巨蚁／火蚁及蚁后、巨螳螂、辐蟑 | 小型群体、重型虫兽、巢穴与地点遭遇；不把幼体都列成兵种 |
| 飞行虫类 | 膨胀蝇、卡扎多尔 | 飞行骚扰生物与危险区域；飞行、毒素分别找原型 |
| 壁虎 | 普通、黄金、绿色、火焰壁虎 | 同一形态家族的环境与能力差异；巨大异常个体只作特殊素材 |
| 死亡爪 | 常规与大型死亡爪形象 | 强力怪兽、特殊敌人与人物候选；动作成本单独评估 |
| 地下与水域生物 | 掘地者、湖妖 | 地点生态与特殊敌人；不因名称加入挖地或水战系统 |
| 犬科 | 狗、郊狼、夜行潜猎者 | 普通猎犬、野生遭遇和变异生物分开；不恢复已取消的军团驯兽领主路线 |
| 大型哺乳动物 | 妖怪熊、巨角羊、双头牛 | 野生威胁、牧畜、商队和骑乘外观候选；不默认全作战兽 |
| 小型动物 | 鼹鼠、巨鼠、渡鸦 | 荒野氛围、事件与场景素材，优先级低于主力单位 |
| 尸鬼 | 狂尸鬼与有组织尸鬼的形象区别 | 躯体状态与装备层级；野生敌人不代表尸鬼政权的全部兵表 |
| 超级变种人 | 大型人形、重武器与拼装近战形象 | 大型步兵、重火力及人物素材 |
| 马德雷幽灵人 | 收割者、捕手、搜寻者 | 同一防护服家族，用武器和动作区分职责 |
| 大山脉特殊人形 | 脑切者、Y-17创伤覆盖装具 | 实验人员与装具驱动人形的不同轮廓；骨架与表现独立评估 |
| 分水岭辐照者 | 侦察、猎兵、掠夺、重装及军团残余形象 | 混合旧军装与辐照损伤的资产家族，不照搬每个刷新记录 |
| 植物异变 | 孢子携带者、孢子植物 | 异变人形与固定植物威胁两类，不合成一套泛用生物 |
| 其他特殊生物 | 半人马、外星人 | 稀有遭遇或特殊人物素材，暂不据此建立完整文化 |

| 赛博狗 | 普通、警用、军用 | 机械化犬类、特殊队友与科技战兽形象 |

## 单位身份与地方组织

| 对象 | 值得借用的身份 | 使用方向 |
| --- | --- | --- |
| NCR | 制式步兵、重装步兵、游骑兵、资深游骑兵、工程师、军警 | 正规军层级与专业分工；巡逻、站岗及性别差异不另立单位 |
| 凯撒军团 | 新兵、老兵、伍长、百夫长、旗手、禁卫军、探索者、刺客 | 军阶、武器与战术身份；教练和铁匠可作人物／建筑主题 |
| 维加斯 | 警用与军用保安机器人、赌场守卫、地方帮派成员 | 机械主力与地方人力的身份区别 |
| 兄弟会 | 圣骑士、侦察与技术人员 | 动力甲精锐与辅助人员分层，具体采用服从现有种族方案 |
| 地方武装 | 大可汗成员、炸药帮保镖、大炮族守卫、佣兵 | 共享基础资产、保留组织识别，不自动提升为独立文化 |
| 商旅与军火商 | 商队护卫、旅行者、军火商守卫与工人 | 护卫、随从、建筑、事件与商路素材 |
| 都市与民生 | 天启追随者警卫、自由城守卫、居民、难民、矿工 | 聚落人口、地方驻军及事件身份；不为每种平民建立战斗单位 |
| 特殊人物形象 | 幸运女神、神秘陌生人 | 装备、事件和特殊能力的表现候选，不预设可招募英雄 |

技能书与杂志不单列资产清单，需要研究、装备或事件主题时再取用；普通生活服饰、同款头盔、损坏型号和颜色变体也不逐项展开。
